Не заважає

Папки читаються напряму, без важкого вигляду оболонки Windows. Жодних таймерів чи опитування у простої — можна безпечно тримати відкритим поруч із 3ds Max, іграми чи іншими важкими програмами.

Миттєвий пошук

Вводьте текст, щоб шукати серед імен усіх файлів на ваших дисках. Власний індекс оновлюється в реальному часі — права адміністратора не потрібні.

Стан SVN одразу видно

Позначки «змінено / додано / конфлікт» читаються просто з .svn — папки червоніють, якщо щось усередині змінилося. Git і Perforce — через накладені піктограми Windows.

Як у Провіднику

Ті самі клавіатурні скорочення, повне контекстне меню Windows, перетягування з Провідника та інших програм і до них. Клацніть правою кнопкою на зображенні .webp, щоб зберегти його як PNG або JPG.

Портативний і приватний

Налаштування зберігаються в папці 4Dir. Світла/темна тема, 26 мов, пакетне перейменування, відновлення сеансу та перевірка стану Провідника вже вбудовані.

Як встановити

  1. Завантажте zip кнопкою вище (або з розділу Releases на GitHub). Зелена кнопка «Code → Download ZIP» на GitHub — це лише вихідний код, він не запуститься.
  2. Клацніть zip правою кнопкою → Властивості → поставте позначку Розблокувати → OK. (Інакше Windows показуватиме попередження безпеки щоразу.)
  3. Розпакуйте куди завгодно та двічі клацніть 4Dir.exe. (або 4Dir.vbs, якщо 4Dir.exe заблоковано)

Якщо з’явиться Windows SmartScreen: натисніть Докладніше → Все одно виконати.

Поширені запитання

Він справді безкоштовний?

Так. 4Dir безкоштовний і з відкритим кодом (GPL-3.0). Без реклами, без облікового запису, без пробного періоду.

Чи можна користуватися ним на роботі?

Так. 4Dir — вільне програмне забезпечення за GPL-3.0, тож компанії також можуть користуватися ним безкоштовно, без ліцензійної плати та реєстрації. Оскільки він працює без встановлення, просто переконайтеся, що ваша компанія дозволяє портативні програми.

Він справді швидший за Провідник?

Відкриття папки з 1 000 файлів у новому вікні забрало 0,4 с у 4Dir і близько 2 с у Провіднику. Ще одне вікно додало близько 10 МБ пам’яті в 4Dir і близько 130 МБ у Провіднику. Вимірювання: по 5 разів на одному ПК (Windows 11, SSD). Якщо в одній папці десятки тисяч файлів, різниця зменшується.

Чи надсилає він якісь дані?

Жодних персональних даних. Раз на день він лише перевіряє, чи є нова версія (це можна вимкнути в меню «Інструменти»).

Щось пішло не так?

Інструменти → Зберегти журнал для звіту про проблему, потім натисніть «Надіслати електронною поштою» (або надішліть zip на support@4dir.net). Користувачі GitHub також можуть створити issue.
