Возможности

До 20 панелей

Раскладки на 1, 2, 3, 4 или 6 панелей одним щелчком или любая сетка до 5 × 4. У каждой панели свои вкладки.

Не мешает работе

Папки читаются напрямую, без тяжёлого представления оболочки Windows. В простое нет таймеров и опросов — можно держать открытым рядом с 3ds Max, играми и другими тяжёлыми программами.

Мгновенный поиск

Начните печатать — поиск по всем именам файлов на дисках. Собственный индекс обновляется в реальном времени, права администратора не нужны.

Статус SVN с первого взгляда

Значки «изменён / добавлен / конфликт» читаются прямо из .svn; папки краснеют, если внутри что-то изменилось. Git и Perforce — через значки-наложения Windows.

Как Проводник

Те же сочетания клавиш, полное контекстное меню Windows, перетаскивание в Проводник и другие программы и обратно. Изображение .webp можно сохранить как PNG или JPG через правый клик.

Портативно и приватно

Настройки хранятся в папке 4Dir. Светлая/тёмная тема, 10 языков, пакетное переименование, восстановление сеанса и диагностика Проводника встроены.

Установка

  1. Скачайте zip кнопкой выше (или в разделе Releases на GitHub). Зелёная кнопка «Code → Download ZIP» на GitHub содержит только исходный код и не запустится.
  2. Щёлкните архив правой кнопкой → Свойства → отметьте Разблокировать → OK. (Иначе Windows будет каждый раз показывать предупреждение.)
  3. Распакуйте в любое место и дважды щёлкните 4Dir.exe. (или 4Dir.vbs, если 4Dir.exe заблокирован)

Если появится Windows SmartScreen: нажмите Подробнее → Выполнить в любом случае.

Частые вопросы

Это правда бесплатно?

Да. 4Dir — бесплатная программа с открытым кодом (GPL-3.0). Без рекламы, без регистрации, без пробного периода.

Можно ли использовать на работе?

Да. 4Dir — свободное ПО под GPL-3.0, поэтому компании тоже могут пользоваться им бесплатно, без лицензий и регистрации. Он работает без установки — проверьте только, разрешает ли ваша компания портативные программы.

Он правда быстрее Проводника?

Папка с 1000 файлов в новом окне: 4Dir — 0,4 с, Проводник — около 2 с. Ещё одно окно: у 4Dir около 10 МБ памяти, у Проводника около 130 МБ. Измерено по 5 раз на одном ПК (Windows 11, SSD). Если в папке десятки тысяч файлов, разница меньше.

Отправляет ли он данные?

Никаких личных данных. Раз в день проверяется только наличие новой версии (можно отключить в меню «Сервис»).

Что-то пошло не так?

Сервис → Сохранить журнал для отчёта о проблеме и нажмите «Отправить по почте» (или пришлите zip на support@4dir.net). Также можно создать issue на GitHub.
