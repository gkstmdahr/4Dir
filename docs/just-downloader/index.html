Install

  1. Download the APK with the button above (or from GitHub Releases).
  2. Open the APK on your phone.
  3. If asked, allow your browser or file app to install unknown apps, then tap Install.

A Google Play edition is coming. Because of Play policy it has fewer supported sites and updates its download engine only with app updates. Both editions can be installed side by side.

FAQ

Is it really free?

Yes. Free and open source (GPL‑3.0). No sign‑up, no trial.

Does it send my data anywhere?

No personal data. Nothing goes to the developer unless you send an error report yourself. Privacy policy

Which sites work?

Most popular video sites work with a link. If a link doesn't work, open the page in the built‑in browser, play the video and tap "Download" on it. Videos protected by DRM (paid streaming services) can't be saved.

Something went wrong?

Settings → Help → Report a problem writes a mail to support@4dir.net with the app log attached. GitHub users can also open an issue: GitHub.
