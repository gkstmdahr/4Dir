機能

リンクを貼るだけ

よく使われる動画サイトの多くはリンクを貼るだけでOK。

ストリーム取得

リンクでだめなときはブラウザでページを開いて再生し、「ストリーム取得」を押すと実際の動画ファイルをダウンロードします。

画面録画

ストリームを取得できないときは、再生中の動画を録画できます。コピー防止がかかった有料配信の動画は保存できません。

速くて控えめ

大きなファイルは分割して速くダウンロード。サイトに負担をかけないよう接続数は少なめです。

ポータブル

展開してすぐ実行。設定はソフトのフォルダ内にだけ保存されます。

インストール

  1. 上のボタンから zip ファイルをダウンロードします。
  2. zip ファイルを右クリック → プロパティ → 許可するにチェック → OK。
  3. 好きな場所に展開し、フォルダ内の .vbs ファイルをダブルクリックします。

Windows のセキュリティ（SmartScreen）が出たら詳細情報 → 実行。

just downloader を応援する

just downloader は無料です。時間の節約になったなら、ささやかな支援が次のアップデートの力になります。
