使い方

ソフトの画面は今のところ韓国語のみです。ボタン名は [ ] で示しています。

  1. リンクを貼る — 動画ページのアドレスをコピーして [＋ 링크 붙여넣기]（リンクを貼り付け）をクリック。複数なら行ごとにコピー、アドレスをウィンドウにドラッグしてもOK。
  2. 画質を選べば開始 — 画質と「動画」または「音声のみ（mp3）」を選ぶと自動でダウンロードします。[저장 폴더 열기]（保存フォルダを開く）でファイルを確認。
  3. リンクでだめなとき — [로그인 사이트]（ログインサイト）をクリック。開いたブラウザで（必要ならログインして）動画を再生し、[스트림 잡기]（ストリーム取得）をクリックすると実際の動画ファイルをダウンロードします。
  4. それでもだめなら録画 — [● 녹화 시작]（録画開始）→ 終わったら [정지·저장]（停止・保存）。動画の長さだけ時間がかかり、mp4 で保存されます。
  • 一部だけ：「区間」に 0:30 ~ 1:45 のように入力（空欄なら全体）。
  • 字幕：チェックすると字幕（.srt）も保存（ある場合）。
  • 再生リスト：再生リストのアドレスを入れると「全部 / この動画だけ」を聞きます。
  • 失敗した項目：一覧で右クリック → [다시 다운로드]（再ダウンロード）。
  • ダウンロード中に止める：[■ 취소]（キャンセル）。

機能

リンクを貼るだけ

よく使われる動画サイトの多くはリンクを貼るだけでOK。

ストリーム取得

リンクでだめなときはブラウザでページを開いて再生し、「ストリーム取得」を押すと実際の動画ファイルをダウンロードします。

画面録画

ストリームを取得できないときは、再生中の動画を録画できます。コピー防止がかかった有料配信の動画は保存できません。

速くて控えめ

大きなファイルは分割して速くダウンロード。サイトに負担をかけないよう接続数は少なめです。

ポータブル

展開してすぐ実行。設定はソフトのフォルダ内にだけ保存されます。

インストール

  1. 上のボタンから zip ファイルをダウンロードします。
  2. zip ファイルを右クリック → プロパティ → 許可するにチェック → OK。
  3. 好きな場所に展開し、フォルダ内の .vbs ファイルをダブルクリックします。

Windows のセキュリティ（SmartScreen）が出たら詳細情報 → 実行。

just downloader を応援する

just downloader は無料です。時間の節約になったなら、ささやかな支援が次のアップデートの力になります。
