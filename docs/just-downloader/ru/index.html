Как это выглядит

Вставьте ссылку, нажмите «Скачать» — и загрузка сразу начнётся. Она продолжится с уведомлением о ходе, даже если вы выйдете из приложения или выключите экран. (Приложение в видео на английском.)

Возможности

Вставьте ссылку

Работает с большинством популярных видеосайтов.

Кнопка «Скачать» на видео

Во встроенном браузере над воспроизводимым видео появляется кнопка «Скачать» — помогает на многих сайтах, где ссылка не срабатывает.

Сразу для монтажа

Сохраняется в Movies/VideoRef. «Совместимость важнее» выбирает H.264 + AAC, чтобы монтажные приложения сразу открывали файл.

Работает в фоне

Продолжает загрузку при выключенном экране. «Скачивать только по Wi-Fi», максимальное разрешение.

Установка

Откройте скачанный APK на телефоне. Если появится запрос, разрешите браузеру или файловому менеджеру устанавливать неизвестные приложения.

Скоро появится версия для Google Play. Из‑за правил Play она поддерживает меньше сайтов и обновляет программу загрузки только вместе с приложением. Обе версии можно установить одновременно.

Проблемы?

Настройки → Помощь → Сообщить о проблеме создаёт письмо на support@4dir.net с журналом приложения во вложении. Исходный код и сообщения об ошибках: GitHub (GPL‑3.0).
