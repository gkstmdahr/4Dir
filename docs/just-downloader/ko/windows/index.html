기능

주소 넣고 받기

많이 쓰는 영상 사이트 대부분은 주소만 넣으면 됩니다.

스트림 잡기

주소로 안 되면 브라우저로 페이지를 열어 재생한 뒤 [스트림 잡기]를 누르세요. 실제 영상 파일을 받습니다.

화면 녹화

스트림을 못 잡을 때는 재생 중인 영상을 녹화합니다. 복제 방지가 걸린 유료 스트리밍 영상은 받을 수 없습니다.

빠르고 무리 없이

큰 파일은 나눠 받아 빠르고, 사이트에 무리가 가지 않게 연결 수를 낮게 유지합니다.

휴대용

압축만 풀면 바로 실행. 설정은 프로그램 폴더 안에만 남습니다.

설치

  1. 위 버튼으로 zip 파일을 받습니다.
  2. 받은 zip 파일 우클릭 → 속성 → 차단 해제 체크 → 확인.
  3. 아무 곳에나 압축을 풀고 폴더 안의 .vbs 파일을 더블클릭합니다.

윈도우 보안(SmartScreen) 창이 뜨면 추가 정보 → 실행.
