이렇게 씁니다

프로그램 화면은 10개 언어를 지원합니다. 오른쪽 위 칸에서 고르세요.

  1. 주소 붙여넣기 — 영상 페이지 주소를 복사(Ctrl+C)하고 [＋ 링크 붙여넣기]를 누르세요. 여러 개면 여러 줄로 복사하면 되고, 주소를 창에 끌어다 놓아도 됩니다.
  2. 화질 고르면 끝 — 화질과 '영상' 또는 '소리만(mp3)'을 고르면 자동으로 받습니다. 받은 파일은 [저장 폴더 열기]로 확인하세요.
  3. 주소로 안 될 때 — [로그인 사이트]를 누르고, 열린 브라우저에서 (필요하면 로그인 후) 영상을 재생한 뒤 [스트림 잡기]를 누르세요. 실제 영상 파일을 받습니다.
  4. 그래도 안 되면 녹화 — [● 녹화 시작] → 끝나면 [정지·저장]. 영상 길이만큼 걸리고 mp4로 저장됩니다.
  • 일부만 받기: '구간'에 0:30 ~ 1:45 처럼 넣으면 그 부분만 받습니다(비우면 전체).
  • 자막: 체크하면 자막(.srt)도 함께 저장합니다(있는 경우).
  • 재생목록: 재생목록 주소를 넣으면 '전체 / 이 영상만'을 물어봅니다.
  • 실패한 항목: 목록에서 우클릭 → [다시 다운로드].
  • 받는 중 멈추기: [■ 취소].

기능

주소 넣고 받기

많이 쓰는 영상 사이트 대부분은 주소만 넣으면 됩니다.

스트림 잡기

주소로 안 되면 브라우저로 페이지를 열어 재생한 뒤 [스트림 잡기]를 누르세요. 실제 영상 파일을 받습니다.

화면 녹화

스트림을 못 잡을 때는 재생 중인 영상을 녹화합니다. 복제 방지가 걸린 유료 스트리밍 영상은 받을 수 없습니다.

빠르고 무리 없이

큰 파일은 나눠 받아 빠르고, 사이트에 무리가 가지 않게 연결 수를 낮게 유지합니다.

휴대용

압축만 풀면 바로 실행. 설정은 프로그램 폴더 안에만 남습니다.

설치

  1. 위 버튼으로 zip 파일을 받습니다.
  2. 받은 zip 파일 우클릭 → 속성 → 차단 해제 체크 → 확인.
  3. 아무 곳에나 압축을 풀고 폴더 안의 .vbs 파일을 더블클릭합니다.
