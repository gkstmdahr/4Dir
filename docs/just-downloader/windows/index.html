Features

Paste a link

Most popular video sites work with just a link.

Grab the stream

If a link doesn't work, open the page in the browser, play the video and press "Grab stream" — the real file is downloaded.

Screen recording

When the stream can't be grabbed, record the playing video instead. Copy‑protected videos from paid streaming services can't be saved.

Fast and gentle

Big files are downloaded in parts for speed, with few connections so the site isn't overloaded.

Portable

Unzip and run. Settings stay in the program folder.

Install

  1. Download the zip with the button above.
  2. Right‑click the zip → Properties → check Unblock → OK.
  3. Unzip anywhere and double‑click the .vbs file in the folder.

If Windows protection (SmartScreen) appears, click More info → Run anyway.
