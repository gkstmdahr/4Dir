使用方式

程式介面目前只有韓文，按鈕名稱以 [括號] 標示。

  1. 貼上連結 — 複製影片頁面網址，按 [＋ 링크 붙여넣기]（貼上連結）。多個連結就分行複製，也可以把網址拖到視窗裡。
  2. 選好畫質就開始 — 選擇畫質和「影片」或「僅音訊（mp3）」，會自動開始下載。按 [저장 폴더 열기]（開啟儲存資料夾）查看檔案。
  3. 連結不行時 — 按 [로그인 사이트]（登入網站），在開啟的瀏覽器裡（需要時先登入）播放影片，再按 [스트림 잡기]（擷取串流），就能下載真正的影片檔。
  4. 還不行就錄影 — 按 [● 녹화 시작]（開始錄影），結束時按 [정지·저장]（停止並儲存）。所需時間與影片長度相同，儲存為 mp4。
  • 只要一部分：在「區間」輸入 0:30 ~ 1:45（留空為全部）。
  • 字幕：勾選後會一併儲存字幕（.srt，有的話）。
  • 播放清單：貼上播放清單網址時會詢問「全部 / 僅此影片」。
  • 失敗的項目：在清單中按右鍵 → [다시 다운로드]（重新下載）。
  • 下載中要停止：按 [■ 취소]（取消）。

功能

貼上連結

大多數常用影片網站貼上連結即可。

擷取串流

連結不行時，在瀏覽器中開啟頁面並播放，再按「擷取串流」，就能下載真正的影片檔。

螢幕錄影

擷取不到串流時，可以錄下正在播放的影片。有防複製保護的付費串流影片無法儲存。

又快又穩

大檔案分段下載，速度快，同時保持較少連線，不造成網站負擔。

免安裝

解壓縮即可執行，設定只存在程式資料夾裡。

安裝

  1. 用上方按鈕下載 zip 檔。
  2. 在 zip 檔上按右鍵 → 內容 → 勾選解除封鎖 → 確定。
  3. 解壓縮到任意位置，按兩下資料夾裡的 .vbs 檔。

如果出現 Windows 安全性（SmartScreen）視窗，按其他資訊 → 仍要執行。
