Code signing policy

Status: release files are not code-signed. Windows may show a SmartScreen warning the first time you run 4Dir (More info > Run anyway). To make sure the file is genuine, check the SHA256 fingerprint shown on the download page and on GitHub Releases.

How release files are built

  • 4Dir.exe — the small starter program in the release zip. It only starts the bundled Python with 4Dir's program files (the same job as 4Dir.vbs). Source: launcher/4Dir_launcher.cs.
  • It is built by GitHub Actions directly from the public source code (build logs, workflow build-exe.yml).
  • The bundled Python runtime (python.exe, pythonw.exe) is the official build, signed by the Python Software Foundation. Third-party components keep their own licenses (see the licenses folder in the zip).

Maintainer

  • gkstmdahr — writes, reviews and publishes every release.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The only network access is the new-version check: once a day 4Dir reads https://4dir.net/version.json (a small public file; nothing about you or your files is sent). Turn it off in Tools > Check for new version at startup (once a day). There is no telemetry, no ads and no account.
