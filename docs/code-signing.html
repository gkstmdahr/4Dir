Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: applying to SignPath Foundation. Until it is approved, release files are not signed by this program — check the SHA256 fingerprint shown on the download page instead.

What is signed

  • 4Dir.exe — the small starter program in the release zip. It only starts the bundled Python with 4Dir's program files (the same job as 4Dir.vbs). Source: launcher/4Dir_launcher.cs.
  • It is built by GitHub Actions directly from the public source code (build logs, workflow build-exe.yml). Files built on a personal PC are never signed.
  • The bundled Python runtime (python.exe, pythonw.exe) is the official build, already signed by the Python Software Foundation. Third-party components keep their own licenses (see the licenses folder in the zip).

Team roles

  • Committers and reviewers: gkstmdahr
  • Approvers: gkstmdahr — every signing request is approved by hand, one release at a time.

All accounts used for the source code, builds and signing use multi-factor authentication.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The only network access is the new-version check: once a day 4Dir reads https://4dir.net/version.json (a small public file; nothing about you or your files is sent). Turn it off in Tools > Check for new version at startup (once a day). There is no telemetry, no ads and no account.
