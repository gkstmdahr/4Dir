Funktionen

Bis zu 20 Bereiche

Layouts mit 1, 2, 3, 4 oder 6 Bereichen per Klick oder ein beliebiges Raster bis 5 × 4. Jeder Bereich hat eigene Tabs.

Bremst nichts aus

Ordner werden direkt gelesen, ohne die schwere Windows-Shell-Ansicht. Im Leerlauf keine Timer und kein Polling – kann neben 3ds Max, Spielen oder anderen schweren Programmen offen bleiben.

Sofortsuche

Tippen und alle Dateinamen auf deinen Laufwerken durchsuchen. Der eigene Index aktualisiert sich in Echtzeit – ohne Administratorrechte.

SVN-Status auf einen Blick

Symbole für geändert / hinzugefügt / Konflikt direkt aus .svn gelesen – Ordner werden rot, wenn sich darin etwas geändert hat. Git und Perforce über Windows-Overlays.

Wie der Explorer

Gleiche Tastenkürzel, das vollständige Windows-Kontextmenü, Drag & Drop mit dem Explorer und anderen Programmen. .webp-Bilder per Rechtsklick als PNG oder JPG speichern.

Portabel und privat

Einstellungen bleiben im 4Dir-Ordner. Helles/dunkles Design, 10 Sprachen, Stapelumbenennung, Sitzungswiederherstellung und Explorer-Diagnose inklusive.

Installation

  1. Lade die Zip-Datei über die Schaltfläche oben herunter (oder unter Releases auf GitHub). Das grüne „Code → Download ZIP“ auf GitHub enthält nur den Quellcode und startet nicht.
  2. Rechtsklick auf die Zip-Datei → Eigenschaften → Zulassen ankreuzen → OK. (Sonst zeigt Windows jedes Mal eine Sicherheitswarnung.)
  3. An einen beliebigen Ort entpacken und 4Dir.exe doppelklicken. (oder 4Dir.vbs, falls 4Dir.exe blockiert wird)

Wenn Windows SmartScreen erscheint: Weitere Informationen → Trotzdem ausführen.

Häufige Fragen

Ist es wirklich kostenlos?

Ja. 4Dir ist kostenlos und Open Source (GPL-3.0). Keine Werbung, kein Konto, keine Testphase.

Darf ich es in der Firma nutzen?

Ja. 4Dir ist freie Software unter GPL-3.0 und auch für Firmen kostenlos, ohne Lizenzgebühr oder Registrierung. Da es ohne Installation läuft, prüfe nur, ob deine Firma portable Programme erlaubt.

Ist er wirklich schneller als der Explorer?

Einen Ordner mit 1.000 Dateien in einem neuen Fenster öffnen: 4Dir 0,4 s, Explorer etwa 2 s. Ein weiteres Fenster kostete bei 4Dir etwa 10 MB Speicher, beim Explorer etwa 130 MB. Je 5-mal gemessen auf demselben PC (Windows 11, SSD). Bei Zehntausenden Dateien in einem Ordner wird der Abstand kleiner.

Sendet es Daten?

Keine persönlichen Daten. Es prüft nur einmal täglich, ob es eine neue Version gibt (abschaltbar unter Extras).

Probleme?

Extras → Protokoll für Problembericht speichern und „Per E-Mail senden“ drücken (oder die Zip-Datei an support@4dir.net schicken). Auf GitHub geht auch ein Issue.
