機能

最大 20 ペイン

1・2・3・4・6 ペインをワンクリックで、または最大 5 × 4 の自由なグリッドに。ペインごとに独立したタブ。

PC を重くしない

重い Windows シェルビューを使わず、フォルダーを直接読み込みます。待機中はタイマーもポーリングもなし。3ds Max やゲームなど重いアプリの横で開いたままでも安心です。

すぐに見つかる検索

入力するだけで全ドライブのファイル名を検索。独自インデックスがリアルタイムで更新され、管理者権限は不要です。

SVN の状態がひと目で

.svn を直接読んで変更・追加・競合のバッジを表示。中身が変わったフォルダーは赤に。Git・Perforce は Windows のオーバーレイで表示。

エクスプローラーと同じ操作感

同じショートカットキー、Windows の右クリックメニューそのまま、エクスプローラーや他のアプリとのドラッグ＆ドロップ。

ポータブルでプライバシーも安心

設定は 4Dir フォルダー内だけに保存。ライト/ダーク、10 言語、一括リネーム、セッション復元、エクスプローラー診断を搭載。

インストール方法

  1. 上のボタン（または GitHub の Releases）から zip をダウンロードします。GitHub の緑の「Code → Download ZIP」はソースコードのみで、そのままでは動きません。
  2. zip を右クリック → プロパティ → 許可するにチェック → OK。（しないと毎回セキュリティ警告が表示されます）
  3. 好きな場所に展開して 4Dir.vbs をダブルクリック。

Windows SmartScreen が表示されたら 詳細情報 → 実行 をクリック。

よくある質問

本当に無料？

はい。4Dir は無料のオープンソース（GPL-3.0）です。広告・アカウント登録・試用期間はありません。

本当にエクスプローラーより速いの？

ファイル 1,000 個のフォルダーを新しいウィンドウで開くと、4Dir は 0.4 秒、エクスプローラーは約 2 秒でした。ウィンドウを 1 つ増やしたときのメモリ増加は 4Dir 約 10 MB、エクスプローラー約 130 MB。同じ PC（Windows 11・SSD）で各 5 回測った値です。1 つのフォルダーに数万ファイルあると差は小さくなります。

データを送信する？

個人情報は送信しません。1 日 1 回、新しいバージョンがあるかを確認するだけです（ツールメニューでオフにできます）。

問題が起きたら？

ツール → 問題報告用ログを保存 → 通知の「メールで送る」を押すか、zip を support@4dir.net に送ってください。GitHub の Issue でも受け付けます。
