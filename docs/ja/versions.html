バージョン履歴

4Dir の全バージョンと変更点です。最新版をおすすめします。必要な方のために以前のバージョンも残しています。

v0.9.73 最新

2026-10-30⬇ ダウンロード SHA256
  • 新機能：4Dir.exe で起動できます。SmartScreen やウイルス対策ソフトに止められた場合は、これまでどおり 4Dir.vbs で起動できます（働きは同じ）。4Dir.exe のコード署名は申請中です。

v0.9.72

2026-10-29⬇ ダウンロード SHA256
  • 修正：一部のファイルでバージョン管理のオーバーレイアイコン（Git・Perforce など）がときどき表示されなかった問題。

v0.9.71

2026-10-29⬇ ダウンロード SHA256
  • 新機能：他のプログラムを使っていても Ctrl+Alt+F で 4Dir が前面に出て、すぐ検索欄に入力できます。キーは ツール → ショートカット設定 で変更できます。
  • アドレスバーに cmd や powershell と入力すると、今のフォルダーで開きます（エクスプローラーと同じ）。
  • 検索欄にカーソルがあると青い枠が付き、ウィンドウが狭くても検索欄は隠れません。
  • 検索結果がないときは理由（ネットワークドライブや Google ドライブは最初は検索範囲外）と、検索範囲を変えるボタンを表示します。
  • 新バージョン通知がより安全に：ダウンロードへ はこのサイトと 4Dir の GitHub ページだけを開きます。それ以外のアドレスは開きません。

  • ドラッグ中は画像ファイルの実際の絵が表示され、つかんだ位置のままマウスについてきます（エクスプローラーと同じ）。
