Historique des versions

Toutes les versions de 4Dir avec leurs changements. La dernière version est recommandée ; les anciennes restent disponibles au besoin.

v0.9.72 dernière

2026-10-29⬇ Télécharger SHA256
  • Corrigé : les icônes de superposition du contrôle de version (Git, Perforce, etc.) manquaient parfois sur certains fichiers.

v0.9.71

2026-10-29⬇ Télécharger SHA256
  • Nouveau : appuyez sur Ctrl+Alt+F n'importe où, même dans un autre programme, pour faire apparaître 4Dir avec la recherche prête. Touche modifiable dans Outils → Raccourcis.
  • Tapez cmd ou powershell dans la barre d'adresse pour l'ouvrir dans le dossier actuel, comme dans l'Explorateur.
  • La zone de recherche affiche un contour bleu quand vous y tapez et reste visible même dans une fenêtre étroite.
  • Quand une recherche ne trouve rien, 4Dir explique pourquoi (les lecteurs réseau et Google Drive ne sont pas inclus au départ) avec un bouton pour changer la portée.
  • Avis de mise à jour plus sûr : Télécharger n'ouvre plus que ce site ou la page GitHub du projet. Toute autre adresse est ignorée.

v0.9.67

2026-10-24⬇ Télécharger SHA256
  • Corrigé : en affichage icônes et liste, faire glisser un fichier en sélectionnait plusieurs au lieu de le déplacer.
  • Pendant le glisser, les images affichent leur propre aperçu et suivent la souris depuis l'endroit saisi, comme dans l'Explorateur.
