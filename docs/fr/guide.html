Mode d'emploi de 4Dir

Chaque fonction est présentée par une courte démonstration animée. Les raccourcis sont presque les mêmes que dans l'Explorateur Windows : si vous l'utilisez, vous en connaissez déjà la moitié.

Zones de l'écran

1 Diviser les volets (Disposition)

  • Le bouton Disposition de la barre d'outils divise en 1·2·3·4·6 volets ou en grille personnalisée (colonnes×lignes).
  • Chaque volet ouvre ses propres dossiers et onglets. Le volet cliqué prend une bordure bleue et devient le « volet actif ».

Raccourci: Ctrl + 1~6

Haut de page ↑

2 Onglets · Onglets sur plusieurs lignes

  • + pour un nouvel onglet, × pour fermer. Faites glisser un onglet pour le réordonner ou le détacher vers un autre volet ou hors de la fenêtre.
  • Les onglets en trop passent à la ligne (désactivable dans Paramètres ▸ Général).

Raccourci: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

Haut de page ↑

3 Barre de favoris

  • Faites glisser un dossier fréquent sur la barre de favoris pour l'ajouter. Cliquez pour l'ouvrir dans le volet actif.
  • Clic droit pour renommer, supprimer ou créer un groupe.

Raccourci: Ctrl + D

Haut de page ↑

4 Volet de navigation · Épingler le dossier

  • En haut du volet de navigation gauche : favoris 4Dir, puis favoris Windows et Ce PC.
  • Activez 📌 Épingler le dossier : l'arborescence reste en place quand vous ouvrez d'autres dossiers — pratique pour glisser des fichiers dans un dossier déplié.

Haut de page ↑

5 Barre d'adresse

  • Cliquez sur un bouton du chemin pour aller à ce dossier ; sur un espace vide pour saisir un chemin.

Raccourci: Alt + D  ·  Ctrl + L

Haut de page ↑

6 Boutons de type

  • Les boutons [Tous][JPG][PNG]… en haut n'affichent que ce type dans tous les volets. Ctrl+clic = plusieurs types.

Haut de page ↑

7 Affichage

  • Basculez entre Détails, Liste et Icônes (petites à très grandes). Par dossier, par volet ou identique partout : Paramètres ▸ Général.

Raccourci: Ctrl + Molette

Haut de page ↑

8 Volet de visualisation

  • Sélectionnez une image, une vidéo, un PDF ou un document pour l'afficher aussitôt. Les PDF se feuillettent et se modifient via ✎ Modifier.

Raccourci: Alt + P  ·  Space

Haut de page ↑

9 Notes

  • Fenêtre de notes pour tâches, listes de contrôle et images. Vous pouvez aussi définir des rappels.

Raccourci: Alt + M

Haut de page ↑

Opérations sur les fichiers

10 Copier · Déplacer entre volets

  • Faites glisser des fichiers vers un autre volet pour copier (autre lecteur) ou déplacer (même lecteur).
  • Ctrl+glisser = copier, Shift+glisser = déplacer. F6 / Shift+F6 = copier / déplacer la sélection vers le volet voisin.

Raccourci: F6  ·  Shift + F6

Haut de page ↑

11 Déposer sur le volet de navigation

  • Déposer des fichiers sur un dossier du volet de navigation gauche les copie ou déplace aussi.

Haut de page ↑

12 Même dossier dans le volet voisin

  • Ouvre aussi le dossier actuel dans le volet voisin. Nouvel onglet ou remplacer l'onglet actuel : Paramètres ▸ Général.

Raccourci: Ctrl + =

Haut de page ↑

13 Saisir pour trouver

  • Dans la liste, tapez vite (en 1 seconde) les premières lettres d'un nom pour y aller. Ex. : de → debug.

Haut de page ↑

14 Renommer · Renommage par lot

  • F2 = renommer (extension conservée). Plusieurs sélectionnés + F2 = fenêtre de renommage par lot (numérotation, remplacement, casse).

Raccourci: F2

Haut de page ↑

15 Ajuster la largeur des colonnes

  • En affichage Détails, ajuste la largeur pour voir les noms longs en entier. Aussi par clic droit sur l'en-tête.

Raccourci: Ctrl + Num +

Haut de page ↑

Outils

16 Rechercher partout

  • Tapez dans la zone de recherche en haut pour chercher aussitôt dans tous les dossiers indexés. Portée : Paramètres ▸ Recherche.

Raccourci: Ctrl + Shift + F

Haut de page ↑

17 Comparer deux volets

  • Compare les fichiers de même nom de deux volets et sélectionne ceux présents d'un seul côté ou plus récents → F6 les copie de l'autre côté.

Raccourci: Shift + F2

Haut de page ↑

18 Modifier le PDF

  • Clic droit sur un PDF ▸ Outils 4Dir ▸ Modifier le PDF, ou ✎ Modifier dans l'aperçu.
  • Pages : pivoter, supprimer, réordonner, insérer / Annoter : stylo, surligneur, zone de texte / Scinder : par page, par plage, toutes les N pages.

Haut de page ↑

19 Éditeur d'image

  • Clic droit sur une image ▸ Outils 4Dir ▸ Modifier l'image, ou ✎ Modifier dans l'aperçu — rogner, texte, flèches, mosaïque, luminosité.

Haut de page ↑

20 Ce PC

  • Taille totale, espace libre et barre d'utilisation pour chaque lecteur (comme l'Explorateur de fichiers).

Haut de page ↑

21 Paramètres

  • Langue, thème, fenêtre, onglets, affichage, volet de navigation, raccourcis, couleurs, recherche et sauvegarde au même endroit. Les changements s'appliquent aussitôt.

Raccourci: Ctrl + ,

Haut de page ↑

Autres points

  • Clair/sombre et la langue se trouvent dans le menu Affichage. La langue change après le redémarrage de 4Dir.
  • Si 4Dir se comporte bizarrement, cliquez sur Outils → Enregistrer le journal pour signaler un problème et envoyez le zip créé à support@4dir.net. Le journal nous sert à trouver la cause.
