Nouveautés de la v0.9.109

  • Nouveaux outils (clic droit ▸ Outils 4Dir, ou menu Outils) : visionneuse texte / hex (F3) · carte d'utilisation du disque — voir ce qui remplit un dossier ou un lecteur · synchroniser des dossiers entre deux volets (A → B, A ← B ou dans les deux sens, sous-dossiers compris, avec un mode miroir optionnel qui envoie le surplus à la Corbeille) · redimensionner et convertir des images par lot (JPG, PNG, WebP, BMP ; les originaux ne sont jamais écrasés) · modifier dates et attributs de nombreux fichiers d'un coup.
  • Étiquettes : ajoutez des étiquettes texte aux fichiers et dossiers (clic droit ▸ Étiquettes) — une colonne Étiquettes apparaît, et Outils ▸ Afficher par étiquette rassemble les éléments étiquetés où qu'ils soient. Groupes virtuels : réunissez des fichiers de dossiers différents sous un nom sans les déplacer (clic droit ▸ Ajouter au groupe virtuel). Boutons personnalisés dans la barre du haut : lancez vos programmes avec les fichiers sélectionnés ({files}, {folder}…). FTP / FTPS : parcourez un serveur comme un dossier (Outils ▸ Se connecter en FTP… ou tapez ftp://… dans la barre d'adresse), ouvrez, téléchargez, envoyez, renommez et supprimez ; les mots de passe mémorisés vont uniquement dans le Gestionnaire d'identification Windows.
  • Win+E ouvre 4Dir (Paramètres ▸ Général ▸ Windows, désactivé par défaut) : une nouvelle fenêtre vide avec un volet sur Ce PC ; désactivez pour retrouver l'Explorateur. Menu contextuel rangé : ★ Favoris 4Dir en haut, puis le plus utilisé, le reste dans Outils 4Dir ▸. Les sous-menus comme Donner l'accès à se remplissent maintenant aussi par clic droit dans un espace vide. La roue des paramètres est après Toujours au premier plan, le numéro de version a quitté la barre de menus (il est dans le titre), et les textes de la file de copie sont traduits.
  • Corrections : le volet de navigation partagé garde sa largeur après un redémarrage, et les volets de navigation par volet gardent la leur après un changement de mode ; après le chargement d'une disposition enregistrée, le volet partagé suit le volet actif ; Entrée du pavé numérique (et Ctrl/Alt+Entrée du pavé) fonctionne dans la liste ; Espace referme de nouveau la fenêtre d'aperçu quand rien n'est en lecture. Fonctionnalités

Jusqu'à 20 volets

Dispositions à 1, 2, 3, 4 ou 6 volets en un clic, ou n'importe quelle grille jusqu'à 5 × 4. Chaque volet a ses propres onglets.

Discret

Les dossiers sont lus directement, sans la lourde vue du shell Windows. Aucun minuteur ni sondage au repos : vous pouvez le laisser ouvert à côté de 3ds Max, de jeux ou d'autres applications lourdes.

Recherche instantanée

Tapez pour chercher parmi tous les noms de fichiers de vos disques. Son propre index se met à jour en temps réel, sans droits administrateur.

État SVN en un coup d'œil

Badges modifié / ajouté / conflit lus directement dans .svn ; les dossiers deviennent rouges si quelque chose a changé dedans. Git et Perforce via les superpositions Windows.

Comme l'Explorateur

Mêmes raccourcis clavier, le menu contextuel Windows complet, glisser-déposer avec l'Explorateur et d'autres applications. Clic droit sur une image .webp pour l'enregistrer en PNG ou JPG.

Portable et respectueux de la vie privée

Les réglages restent dans le dossier 4Dir. Thème clair/sombre, 10 langues, renommage par lot, restauration de session et diagnostic de l'Explorateur intégrés.

Installation

  1. Téléchargez le zip avec le bouton ci-dessus (ou depuis Releases sur GitHub). Le bouton vert « Code → Download ZIP » de GitHub ne contient que le code source et ne se lance pas.
  2. Clic droit sur le zip → Propriétés → cochez Débloquer → OK. (Sinon Windows affiche un avertissement de sécurité à chaque fois.)
  3. Décompressez-le où vous voulez et double-cliquez sur 4Dir.exe. (ou 4Dir.vbs si 4Dir.exe est bloqué)

Si Windows SmartScreen apparaît : cliquez sur Informations complémentaires → Exécuter quand même.

Vérifier le téléchargement (facultatif)

Dans l'invite de commandes, lancez certutil -hashfile 4Dir_v0.9.109.zip SHA256 ; le résultat doit correspondre à :

Questions fréquentes

Est-ce vraiment gratuit ?

Oui. 4Dir est gratuit et open source (GPL-3.0). Pas de publicité, pas de compte, pas de période d'essai.

Puis-je l'utiliser au travail ?

Oui. 4Dir est un logiciel libre sous GPL-3.0 : les entreprises peuvent aussi l'utiliser gratuitement, sans licence ni inscription. Comme il fonctionne sans installation, vérifiez simplement que votre entreprise autorise les logiciels portables.

Est-il vraiment plus rapide que l'Explorateur ?

Ouvrir un dossier de 1 000 fichiers dans une nouvelle fenêtre : 0,4 s avec 4Dir, environ 2 s avec l'Explorateur. Une fenêtre de plus : environ 10 Mo de mémoire pour 4Dir, environ 130 Mo pour l'Explorateur. Mesuré 5 fois sur le même PC (Windows 11, SSD). Avec des dizaines de milliers de fichiers dans un dossier, l'écart se réduit.

Envoie-t-il des données ?

Aucune donnée personnelle. Il vérifie seulement une fois par jour si une nouvelle version existe (désactivable dans Outils).

Un problème ?

Outils → Enregistrer le journal pour rapport de problème, puis « Envoyer par e-mail » (ou envoyez le zip à support@4dir.net). Sur GitHub, vous pouvez aussi ouvrir une issue.
