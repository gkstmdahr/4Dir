How to use 4Dir

Each feature is shown with a short moving demo. Shortcuts are mostly the same as in Windows Explorer, so if you have used Explorer you already know half of it.

Screen areas

1 Split panes (Layout)

  • Use the Layout button on the toolbar to split into 1·2·3·4·6 panes, or a custom grid (columns×rows).
  • Each pane opens its own folders and tabs. The pane you click gets a blue border and becomes the 'current pane'.

Shortcut: Ctrl + 1~6

Back to top ↑

2 Tabs · Multi-row tabs

  • + for a new tab, × to close. Drag a tab to reorder it, or move it to another pane or out of the window.
  • Extra tabs wrap to a new row (can be turned off in Settings ▸ General).

Shortcut: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

Back to top ↑

3 Favorites bar

  • Drag a frequently used folder onto the Favorites bar to add it. Click it to open in the current pane.
  • Right-click to rename, remove, or create a group.

Shortcut: Ctrl + D

Back to top ↑

4 Navigation pane · Pin folder

  • At the top of the left navigation pane: 4Dir favorites, then Windows favorites and This PC.
  • Turn on 📌 Pin folder and the tree stays put when you open other folders — handy for dragging files into an expanded folder.

Back to top ↑

5 Address bar

  • Click a path button to go to that folder; click an empty spot to type a path.

Shortcut: Alt + D  ·  Ctrl + L

Back to top ↑

6 Type buttons

  • Click the [All][JPG][PNG]… buttons at the top to show only that type in every pane. Ctrl+click = multiple types.

Back to top ↑

7 View

  • Switch between Details, List, and Icons (small to extra large). Per folder, per pane, or same everywhere: Settings ▸ General.

Shortcut: Ctrl + Wheel

Back to top ↑

8 Preview pane

  • Select an image, video, PDF, or document to preview it instantly. PDFs can be paged through, and ✎ Edit edits them directly.

Shortcut: Alt + P  ·  Space

Back to top ↑

9 Memo

  • A notes window for to-dos, checklists, and pinned images. You can also set reminder times.

Shortcut: Alt + M

Back to top ↑

File operations

10 Copy · Move between panes

  • Drag files to another pane to copy (different drive) or move (same drive).
  • Ctrl+drag = copy, Shift+drag = move. F6 / Shift+F6 = copy / move the selection to the next pane.

Shortcut: F6  ·  Shift + F6

Back to top ↑

11 Drop onto the navigation pane

  • Dropping files onto a folder in the left navigation pane also copies or moves them.

Back to top ↑

12 Same folder in the next pane

  • Opens the current folder in the next pane too. New tab or replace the current tab: Settings ▸ General.

Shortcut: Ctrl + =

Back to top ↑

13 Type to find

  • In the file list, quickly type the first letters of a name (within 1 second) to jump to it. E.g. de → debug.

Back to top ↑

14 Rename · Batch rename

  • F2 = rename (extension kept). Select several and press F2 = Batch rename window (numbering, replace, case).

Shortcut: F2

Back to top ↑

15 Auto-fit column width

  • In Details view, fits column widths so long names show in full. Also via right-click on the header.

Shortcut: Ctrl + Num +

Back to top ↑

Tools

16 Search all

  • Type in the search box at the top to search all indexed folders instantly. Search scope: Settings ▸ Search.

Shortcut: Ctrl + Shift + F

Back to top ↑

17 Compare two panes

  • Compares same-named files in two panes and selects those only on one side or newer → F6 copies them to the other side.

Shortcut: Shift + F2

Back to top ↑

18 Edit PDF

  • Right-click a PDF ▸ 4Dir tools ▸ Edit PDF, or ✎ Edit in the preview.
  • Pages: rotate, delete, reorder, insert / Annotate: pen, highlighter, text box / Split: per page, by range, every N pages.

Back to top ↑

19 Image editor

  • Right-click an image ▸ 4Dir tools ▸ Edit image, or ✎ Edit in the preview — crop, text, arrows, mosaic, brightness.

Back to top ↑

20 This PC

  • Total size, free space, and a usage bar for each drive (like File Explorer).

Back to top ↑

21 Settings

  • Language, theme, window, tabs, view, navigation pane, shortcuts, colors, search, and backup in one place. Changes apply immediately.

Shortcut: Ctrl + ,

Back to top ↑

Other things

  • Light/dark and language are in the View menu. A language change takes effect after you restart 4Dir.
  • If 4Dir starts acting strange, click Tools → Save log for problem report and send the zip it makes to support@4dir.net. We'll look at the log to find the cause.
