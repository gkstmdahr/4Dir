Version history

Every 4Dir release with what changed. The newest version is recommended; older ones stay here in case you need them.

v0.9.130 latest

2026-11-11⬇ Download SHA256
  • Shortcut for a new file: the Windows New types (Text Document, Word, Excel…) can now get a shortcut key and go into My Menu.
  • My Menu items can have their own shortcut; a key already in use is shown in red on both sides, and nothing changes until [Save].
  • Drag to select several files in Details view from any empty spot, another column or the side margins (drag on a name still moves files).
  • Decorate favorites: color, emoji (before or after the name) and bold — right-click a favorite › Decorate.

v0.9.129

2026-11-10⬇ Download SHA256
  • Preview works the same for every file type: ◀ ▶ (always in the same place) and the < > keys go through every file in the folder in list order, like File Explorer — pictures, GIFs, videos, PDFs, text and more.
  • Zoom everywhere: GIFs and videos now zoom with the mouse wheel and can be dragged, like pictures. Pictures, GIFs, videos and PDFs have [Fit] [1:1] [−] [%] [+] buttons (in PDFs the wheel still turns pages).
  • Selecting several pictures now shows the large picture at full resolution (it was blurry), with ◀ ▶ moving within the selection.

v0.9.128

2026-11-10⬇ Download SHA256
  • Windows Photos shows the whole folder: pictures opened from 4Dir in the Photos app (or another Store app) now list every picture in the folder at the bottom and you can go next/previous, the same as from File Explorer. Before, only the one picture was listed.
  • Hide top toolbar items: right-click an empty spot on the top bar (or Settings ▸ General ▸ Top toolbar) to choose which buttons, the search box and the CPU·GPU meter are shown. The View/Tools menus and the settings gear always stay.
  • Preview pane: select several pictures to see one large with a thumbnail strip of the selection below (click or ←→ to switch). Right-click a file or folder ▸ Open in Windows File Explorer (a file opens with it selected).

v0.9.127

2026-11-10⬇ Download SHA256
  • Taskbar pin fixed: a pinned 4Dir no longer turns into a blank white icon or stops working after you unzip a new version into a new folder or move the folder. Existing pins are fixed automatically the first time you run the new version.
  • New in Tools: Synchronized browsing (entering or leaving a folder in one pane moves the other pane to the folder with the same name), Show selected only, and File color rules (e.g. *.max in blue, files changed in the last 7 days in green).
  • Multi-row tabs: choose the maximum number of tab rows (Settings ▸ General ▸ Tabs); extra rows scroll with ▲▼ or the mouse wheel. On 32-bit Windows, 4Dir now explains that it needs 64-bit Windows instead of failing silently.

  • View for everything: choose whether the view (Details, icons…) is remembered per folder, per pane, or the same everywhere — Settings ▸ General or View ▸ View applies to.
  • Settings open about 10× faster and the window is smaller; General settings are grouped into boxes; “Check for new version” shows the result right next to the button.
  • Fixed: script files (.vbs and similar) sometimes did not open from 4Dir.
