Version history

Every 4Dir release with what changed. The newest version is recommended; older ones stay here in case you need them.

v0.9.101 latest

2026-11-05⬇ Download SHA256
  • Shared navigation pane: View ▸ Navigation pane ▸ Shared puts one full-height folder tree on the window's left. Folders you pick open in the pane you used last (locked tabs open a new tab), and the tree follows that pane's folder. Per-pane trees are hidden while it is on and come back when you switch back. The ☰ button (or View ▸ Navigation pane) hides and shows it.

v0.9.99

2026-11-05⬇ Download SHA256
  • Switch saved window layouts with a key: 'Save/Load windows' now has Load most recently saved, Load slot 1 and Load slot 2, plus Set as slot 1/2 and Rename. Assign keys in Keyboard shortcuts (for example Ctrl+Alt+1).
  • Export and import only shortcuts: the Keyboard shortcuts window has Export shortcuts… and Import shortcuts… buttons. Keyboard and mouse shortcuts go into one small file; importing changes only shortcuts, not tabs or window layouts.

v0.9.97

2026-11-05⬇ Download SHA256
  • Icon views: names are no longer cut off in folders that mix folders and files (for example a drive's top folder).
  • Removed drives: tabs that were on a drive you unplug move to This PC instead of showing the old list.
  • Slow drives: opening a drive that is still waking up (like a just-plugged external disk) no longer freezes 4Dir; it opens when the drive answers, and its icon and name fill in.
  • Safely remove: 4Dir lets go of a USB or external drive when Windows asks to eject it, so it no longer says the drive is in use.
  • Notice bar: a ✕ button on the right closes it.

v0.9.95

2026-11-05⬇ Download SHA256
  • Lock tab: right-click a tab > Lock tab. Folders opened from a locked tab (🔒) open in a new tab next to it.
  • USB and external drives appear in This PC as soon as you plug them in, and disappear when removed.

v0.9.94

2026-11-04⬇ Download SHA256
  • Status column in OneDrive and other synced folders: online-only, on this device, always kept (like Explorer).
  • Ctrl+Enter on a file opens its folder location in a new tab (search results and shortcuts), like Everything's Open Path.
  • Export / import settings (Tools): view options, shortcuts, favorites, windows and tabs (with colors), color labels — handy after reinstalling Windows.
  • Faster: large folders open about twice as fast (30,000 files: 1.3 s → 0.5 s).

v0.9.93

2026-11-04⬇ Download SHA256
  • Group by date (Today, Yesterday, This week…) like Windows Explorer — View > Show to turn on.
  • Layouts: 8 new ones (e.g. 1 tall left + 2 right, 3 + 1) — one Layout button opens a picker.
  • Folder sizes in the Size column (sortable; not on network drives). View > Show to turn off.
  • Compare two panes (Shift+F2): files only on one side or newer are marked and selected — press F6 to copy them across.
  • Select by pattern (Ctrl+Shift+A), e.g. *.max; *_stand*.
  • Colors: right-click a tab > Tab color, or files > Color label — 13 colors or any color (kept inside 4Dir only).
  • Find command (Ctrl+Shift+P): type part of any command or menu item and press Enter.
  • Checksum: right-click files > Show checksum (SHA256).
  • Double-click to go up now also works in the empty strips left and right of the list.
  • Closes right away: 4Dir no longer stays running for a minute after closing when a network favorite is slow to answer.

v0.9.87

2026-11-04⬇ Download SHA256
  • Settings carry over: a new version folder copies settings, favorites and open tabs from the previous 4Dir folder next to it on first start.
  • 4Dir.exe works through links: it now starts when run from a shortcut link in another folder (as winget does).

v0.9.86

  • Drop to save: Outlook attachments, web mail images and files from a zip window.
