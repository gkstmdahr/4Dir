Version history

Every 4Dir release with what changed. The newest version is recommended; older ones stay here in case you need them.

v0.9.73 latest

2026-10-30⬇ Download SHA256
  • New: start 4Dir with 4Dir.exe. If SmartScreen or antivirus blocks it, 4Dir.vbs still does the same job. (Code signing for 4Dir.exe has been applied for.)

v0.9.72

2026-10-29⬇ Download SHA256
  • Fixed: version-control overlay icons (Git, Perforce and others) were sometimes missing on some files.

v0.9.71

2026-10-29⬇ Download SHA256
  • New: press Ctrl+Alt+F anywhere — even in another program — to bring up 4Dir with the search box ready. Change the key in Tools → Shortcuts.
  • Type cmd or powershell in the address bar to open it in the current folder — just like Windows Explorer.
  • The search box gets a blue outline while you're typing in it, and it stays visible even in a narrow window.
  • When a search finds nothing, 4Dir now says why (network drives and Google Drive aren't searched at first) with a button to change the search scope.
  • Safer update notice: Get it now opens only this site or this project's GitHub page. Any other address is ignored.

v0.9.67

2026-10-24⬇ Download SHA256
  • Fixed: in icon and list views, dragging a file selected several files instead of moving it.
  • While dragging, images show their own picture, and the picture follows from the spot you grabbed — like Windows Explorer.
