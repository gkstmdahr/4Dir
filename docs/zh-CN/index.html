功能

最多 20 个窗格

一键切换 1、2、3、4、6 窗格布局，或自定义最多 5 × 4 的网格。每个窗格都有独立的标签页。

不拖慢电脑

直接读取文件夹，不使用沉重的 Windows Shell 视图。空闲时没有定时器和轮询——可放心与 3ds Max、游戏等大型程序同时运行。

即时搜索

输入即可搜索所有驱动器上的文件名。自建索引实时更新，无需管理员权限。

SVN 状态一目了然

直接读取 .svn 显示修改/添加/冲突标记，内部有变更的文件夹显示为红色。Git、Perforce 通过 Windows 覆盖图标显示。

用起来像资源管理器

相同的快捷键、完整的 Windows 右键菜单，可与资源管理器及其他程序互相拖放。右键即可把 .webp 图片另存为 PNG 或 JPG。

便携且注重隐私

设置只保存在 4Dir 文件夹内。内置浅色/深色主题、10 种语言、批量重命名、会话恢复和资源管理器诊断。

安装方法

  1. 用上方按钮（或 GitHub 的 Releases）下载 zip。GitHub 上绿色的“Code → Download ZIP”只有源代码，无法直接运行。
  2. 右键 zip → 属性 → 勾选解除锁定 → 确定。（否则每次运行都会出现安全警告）
  3. 解压到任意位置，双击 4Dir.vbs。

如果出现 Windows SmartScreen：点击更多信息 → 仍要运行。

校验下载（可选）

常见问题

真的免费吗？

是的。4Dir 是免费开源软件（GPL-3.0）。无广告、无需账号、无试用期。

可以在公司使用吗？

可以。4Dir 是 GPL-3.0 免费软件，公司也可以免费使用，无需授权费或注册。它无需安装即可运行，请确认公司是否允许使用便携软件。

真的比文件资源管理器快吗？

在新窗口中打开含 1,000 个文件的文件夹：4Dir 用时 0.4 秒，文件资源管理器约 2 秒。多开一个窗口增加的内存：4Dir 约 10 MB，文件资源管理器约 130 MB。同一台电脑（Windows 11，SSD）各测 5 次。单个文件夹有数万个文件时差距会变小。

会发送数据吗？

不会发送个人数据。每天只检查一次是否有新版本（可在“工具”中关闭）。

遇到问题？

工具 → 保存问题报告日志，然后点击“通过邮件发送”（或把 zip 发到 support@4dir.net）。GitHub 用户也可以提交 issue。
