v0.9.71

2026-10-29⬇ 下载 SHA256
  • 新功能：即使在使用其他程序，按 Ctrl+Alt+F 即可调出 4Dir 并直接在搜索框输入。可在 工具 → 快捷键设置 中更改按键。
  • 在地址栏输入 cmd 或 powershell 即可在当前文件夹中打开——与 Windows 资源管理器相同。
  • 搜索框获得焦点时会显示蓝色边框，窗口变窄时搜索框也不会被隐藏。
  • 搜索无结果时会说明原因（网络驱动器和 Google 云端硬盘一开始不在搜索范围内），并提供更改搜索范围的按钮。
  • 更新提示更安全：前往下载 只会打开本网站或本项目的 GitHub 页面，其他地址一律忽略。
