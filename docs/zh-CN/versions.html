版本记录

4Dir 的所有版本及更新内容。建议使用最新版本；旧版本也保留在这里以备需要。

v0.9.107 最新

2026-11-05⬇ 下载 SHA256
  • 设置窗口：点击菜单栏的齿轮按钮（或 Ctrl+,）打开设置窗口，分为常规、文件列表、导航窗格、版本控制、快捷键·鼠标、颜色、搜索、备份、关于，更改立即生效。快捷键、颜色和搜索范围也直接在其中修改。菜单栏精简为 视图 / 工具 / ⚙；“保存/加载窗口”在“工具”中，收藏夹菜单在收藏夹栏的“收藏夹”文字上。
  • 同时比较内容：比较两个窗格（Shift+F2）后，点击通知栏的“同时比较内容”，会实际读取名称和大小相同的文件，内容不同的标为红色；仅日期不同、内容相同的显示为灰色并从 F6 复制选择中去除。后台运行，可随时停止。

v0.9.93

2026-11-04⬇ 下载 SHA256
  • 按日期分组（今天、昨天、本周…），与 Windows 资源管理器相同 — 在 视图 > 显示 中开启。
  • 布局：新增 8 种（如左侧 1 个长窗格 + 右侧 2 个、3 + 1）— 点一个布局按钮即可选择。
  • 文件夹大小：大小列也显示文件夹大小，可按大小排序（网络驱动器除外）。
  • 比较两个窗格（Shift+F2）：仅一侧有或较新的文件会标色并选中 — 按 F6 复制到另一侧。
  • 按模式选择（Ctrl+Shift+A），例如 *.max; *_stand*。
  • 颜色：右键标签 > 标签颜色（13 种或任意颜色），右键文件 > 颜色标签（仅保存在 4Dir 内）。
  • 查找命令（Ctrl+Shift+P）：输入任意功能或菜单名称的一部分后按 Enter。
  • 校验值：右键文件 > 查看校验值 (SHA256)。
  • 双击空白处返回上级现在在列表左右两侧的空白条上也可用。
  • 关闭即退出：网络收藏响应缓慢时，关闭窗口后 4Dir 仍残留一分钟以上的问题已修复。
