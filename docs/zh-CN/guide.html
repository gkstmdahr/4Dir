界面区域说明

1 分割窗格（布局）

  • 用工具栏的布局按钮分为 1·2·3·4·6 个窗格，或自定义（列×行）。
  • 每个窗格各自打开文件夹和标签。单击的窗格显示蓝色边框，成为“当前窗格”。

快捷键: Ctrl + 1~6

回到顶部 ↑

2 标签 · 多行标签

  • + 新建标签，× 关闭。拖动标签可调整顺序，或移到其他窗格、拖出窗口。
  • 标签过多时换到下一行（可在 设置 ▸ 常规 中关闭）。

快捷键: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

回到顶部 ↑

3 收藏夹栏

  • 将常用文件夹拖到收藏夹栏即可添加。单击即在当前窗格中打开。
  • 右键可重命名、删除、创建分组。

快捷键: Ctrl + D

回到顶部 ↑

4 主文件夹

  • 像 Windows 资源管理器的主文件夹一样，一眼查看收藏文件夹和最近项目。在导航窗格顶部或地址栏中点“主文件夹”。
  • 4Dir 运行时，用 Win+E 打开的新窗口也会以主文件夹打开。

回到顶部 ↑

5 导航窗格 · 固定文件夹

  • 左侧导航窗格顶部是 4Dir 收藏夹，下方是 Windows 收藏夹和此电脑。
  • 开启 📌 固定文件夹后，打开其他文件夹时树保持不变 — 方便把文件拖到已展开的文件夹。

回到顶部 ↑

6 地址栏

  • 单击路径按钮转到该文件夹，单击空白处可直接输入路径。

快捷键: Alt + D  ·  Ctrl + L

回到顶部 ↑

7 类型按钮

  • 单击顶部的 [全部][JPG][PNG]… 按钮，所有窗格只显示该类型。Ctrl+单击 = 多种类型。

回到顶部 ↑

8 视图

  • 切换详细信息、列表、图标（小~超大）。按文件夹、按窗格或全部相同：设置 ▸ 常规。

快捷键: Ctrl + 滚轮

回到顶部 ↑

9 预览窗格

  • 选中图片、视频、PDF、文档，即可在 4Dir 窗口右侧窗格中立即预览。用 ◀ ▶ 或 < > 键依次翻看文件夹中的文件。
  • 右键点击预览可将其拆分为独立窗口，或用“仅内容”放大查看图片和文字。视频可 0.25–4 倍速播放。
  • PDF 可翻页，点 ✎ 编辑直接编辑。

快捷键: Alt + P  ·  Space

回到顶部 ↑

10 将一个窗格用作预览

  • 在窗格的“查看”菜单 ▸ 将此窗格用作预览 — 此窗格会大图显示其他窗格中选中的文件。
  • 点击窗格标题栏的 ✕ 返回文件列表，即可回到原来的文件列表。

回到顶部 ↑

11 文件夹预览

  • 在预览中选中文件夹，会把其中的图片和视频以缩略图汇总显示。开启“包含子文件夹”后，子文件夹中的内容也会按文件夹分组显示。
  • 点击缩略图可放大查看，按 Esc 返回列表。

回到顶部 ↑

12 选择列（属性列）

  • 右键点击“详细信息”视图的列标题，可开启状态、属性、备注、标题、标记等 Windows 属性列。
  • 通过“选择更多列”，可像资源管理器一样搜索并选择所有属性。

回到顶部 ↑

13 我的菜单

  • 把常用的程序、文件夹、地址和 4Dir 功能添加到顶部按钮栏。工具 ▸ 编辑我的菜单。
  • 可为每个项目设置快捷键和图标（仅显示图标），并用分隔线分组。传递的值 {files} = 选中的文件。

回到顶部 ↑

14 便笺

  • 可贴待办、清单、图片的便笺窗口。还可设置提醒时间。

快捷键: Alt + M

回到顶部 ↑

文件操作

15 窗格间复制 · 移动

  • 将文件拖到其他窗格即复制（不同驱动器）或移动（同一驱动器）。
  • Ctrl+拖动 = 复制，Shift+拖动 = 移动。F6 / Shift+F6 = 将所选内容复制 / 移动到相邻窗格。

快捷键: F6  ·  Shift + F6

回到顶部 ↑

16 拖放到导航窗格

  • 将文件放到左侧导航窗格的文件夹上也可复制或移动。

回到顶部 ↑

17 在相邻窗格打开同一文件夹

  • 在相邻窗格中也打开当前文件夹。新建标签还是替换当前标签：设置 ▸ 常规。

快捷键: Ctrl + =

回到顶部 ↑

18 键入查找

  • 在文件列表中快速键入名称开头（1 秒内）即可跳到该项。例：de → debug。

回到顶部 ↑

19 重命名 · 批量重命名

  • F2 = 重命名（保留扩展名）。选中多个后按 F2 = 批量重命名窗口（编号、替换、大小写）。

快捷键: F2

回到顶部 ↑

20 自动调整列宽

  • 在详细信息视图中调整列宽以完整显示长名称。也可右键单击列标题。

快捷键: Ctrl + Num +

回到顶部 ↑

工具

21 全局搜索

  • 在顶部搜索框中输入即可立即搜索所有已索引的文件夹。搜索范围：设置 ▸ 搜索。
  • 不仅按名称，也能按文档内的词语（Excel、Word、PDF、韩文(HWP)…）搜索 — 使用 Windows 索引。

快捷键: Ctrl + Shift + F

回到顶部 ↑

22 比较两个窗格

  • 比较两个窗格中同名文件，选出仅一侧存在或较新的文件 → 按 F6 复制到另一侧。

快捷键: Shift + F2

回到顶部 ↑

23 编辑 PDF

  • 右键单击 PDF ▸ 4Dir 工具 ▸ 编辑 PDF，或预览中的 ✎ 编辑。
  • 页面：旋转、删除、排序、插入 / 批注：笔、荧光笔、文本框 / 拆分：每页、按范围、每 N 页。

回到顶部 ↑

24 图片编辑

  • 右键单击图片 ▸ 4Dir 工具 ▸ 编辑图片，或预览中的 ✎ 编辑 — 裁剪、文字、箭头、马赛克、亮度。

回到顶部 ↑

25 文件颜色规则

  • 工具 ▸ 文件颜色规则 — 按扩展名、名称、日期条件为文件文字着色。例：*.max 蓝色，7 天内修改的文件绿色。

回到顶部 ↑

26 轻量模式

  • 设置 ▸ 常规 ▸ 轻量模式 — 关闭快速搜索索引和 CPU 显示，并减少预览缓存，以节省内存。
  • 全部搜索会即时扫描文件夹，速度会稍慢。再次关闭后，会立即载入已保存的索引。

回到顶部 ↑

27 此电脑

  • 每个驱动器的总大小、可用空间和使用量条（如同文件资源管理器）。

回到顶部 ↑

28 设置

  • 语言、主题、窗口、标签、视图、导航窗格、快捷键、颜色、搜索、备份集中设置。更改立即生效。

快捷键: Ctrl + ,

回到顶部 ↑

其他

  • 浅色/深色和语言在查看菜单里。语言要重新启动 4Dir 才会切换。
  • 4Dir 表现不对劲时，请点工具 → 保存问题报告日志，把生成的 zip 发到 support@4dir.net。我们会根据日志查找原因。
