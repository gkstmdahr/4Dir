v0.9.86 에서 바뀐 점

  • 새 기능: 도구 > 단축키 설정 > 마우스에서 마우스 버튼에 기능을 지정합니다 — 오른쪽·가운데·뒤로(4번)·앞으로(5번) 버튼, 그리고 Ctrl·Shift·Alt + 모든 버튼(그냥 왼쪽 클릭만 고정). 원래 쓰임을 바꾸면 빨간 글자로 알려 주고, 막지는 않습니다. 이미 쓰는 키·버튼을 넣으면 새 기능으로 옮기고 양쪽에 빨갛게 알려 주며, 되돌리기·다시 하기로 되돌릴 수 있습니다.
  • 새 기능: 보기 > 정렬 기준에 날짜·길이·만든 날짜·파일 위치·미디어 작성 날짜·사진 크기를 추가했습니다(사진·영상 정보는 뒤에서 읽어 정렬).
  • 새 기능: 자세히 보기의 열 제목을 우클릭해서 보일 열을 고릅니다 — 수정한 날짜·유형·크기·날짜·길이·만든 날짜·미디어 작성 날짜·사진 크기. 열 제목을 끌면 순서가 바뀌고, 누르면 그 열로 정렬합니다.
  • 새 옵션(보기 > 표시): 탭이 하나면 탭 줄 숨기기, 빈 곳을 더블클릭하면 상위 폴더로(기본 켬), 메뉴줄을 접어도 즐겨찾기 줄은 보이기(기본 켬). 탭 줄을 숨겼을 때 새 탭은 Ctrl+T(또는 폴더를 마우스 가운데 버튼으로 클릭)로 엽니다. 탭 줄을 숨겼을 때는 빈 곳 우클릭 메뉴 맨 위에도 새 탭이 나옵니다.
  • 새 기능: 아웃룩 첨부 파일, 웹 메일 본문 이미지, 압축 프로그램 창 안의 파일을 4Dir 에 끌어 놓으면 그 폴더에 저장됩니다(여러 개를 한꺼번에 끌어도 됩니다). 웹 메일 이미지는 원래 파일 이름으로 저장됩니다.

기능

최대 20칸

1·2·3·4·6칸을 버튼 하나로, 또는 가로 5 × 세로 4까지 원하는 대로. 칸마다 탭이 따로 있습니다.

PC를 무겁게 하지 않음

무거운 윈도우 탐색기 화면을 쓰지 않고 폴더를 직접 읽습니다. 쉬고 있을 때는 아무것도 하지 않아 3ds Max·게임 같은 무거운 프로그램 옆에 켜 둬도 안전합니다.

바로 찾는 검색

입력하는 즉시 드라이브의 모든 파일 이름을 찾습니다. 자체 목록이 실시간으로 갱신되고 관리자 권한이 필요 없습니다.

SVN 상태 한눈에

.svn 을 직접 읽어 수정·추가·충돌 표시. 안쪽이 바뀐 폴더는 빨갛게. Git·Perforce 는 윈도우 겹침 아이콘으로.

탐색기와 같은 손맛

같은 단축키, 윈도우 우클릭 메뉴 그대로, 탐색기·다른 프로그램과 끌어다 놓기. webp 그림은 우클릭 한 번으로 PNG·JPG로 저장.

휴대용·개인정보 보호

설정은 4Dir 폴더 안에만. 밝게/어둡게, 10개 언어, 이름 일괄 변경, 창 구성 복구, 탐색기 점검 기본 포함.

설치 방법

  1. 위 버튼(또는 깃허브 Releases)에서 zip 을 받습니다. 깃허브의 초록색 'Code → Download ZIP' 은 소스 코드만 있어 실행되지 않습니다.
  2. 압축 파일 우클릭 → 속성 → 차단 해제 체크 → 확인. (안 하면 실행할 때마다 보안 경고가 뜹니다)
  3. 아무 곳에나 압축을 풀고 4Dir.exe 를 더블클릭. (막히면 4Dir.vbs)

윈도우 보안(SmartScreen) 창이 뜨면 추가 정보 → 실행.

자주 묻는 질문

정말 무료인가요?

네. 무료 오픈소스(GPL-3.0)입니다. 광고·회원가입·체험 기간 없습니다.

회사에서 써도 되나요?

네. GPL-3.0 무료 소프트웨어라 회사에서도 비용·등록 없이 쓸 수 있습니다. 설치 없이 실행하는 프로그램이니, 회사 보안 규정에서 휴대용 프로그램을 허용하는지만 확인해 주세요.

탐색기보다 정말 빠른가요?

파일 1천 개 폴더를 새 창으로 열면 4Dir 0.4초, 탐색기 약 2초 걸렸습니다. 창을 하나 더 열 때 늘어나는 메모리는 4Dir 약 10MB, 탐색기 약 130MB였습니다. 같은 PC(윈도우 11, SSD)에서 5번씩 잰 값입니다. 파일이 수만 개인 폴더에서는 차이가 줄어듭니다.

정보를 보내나요?

개인 정보는 보내지 않습니다. 하루 한 번 새 버전이 있는지만 확인합니다(도구 메뉴에서 끌 수 있음).

문제가 생기면?

도구 → 문제 보고용 로그 저장 → 알림의 '메일로 보내기'를 누르거나, 생긴 zip 을 support@4dir.net 으로 보내 주세요. 깃허브 사용자는 문제 보고(Issue)도 됩니다.
