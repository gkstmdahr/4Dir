화면 영역 안내

1 칸 나누기 (레이아웃)

  • 도구줄의 레이아웃 단추로 1·2·3·4·6칸, 직접 지정(가로×세로)까지 나눕니다.
  • 칸마다 따로 폴더·탭을 엽니다. 누른 칸이 파란 테두리로 '지금 칸'이 됩니다.

단축키: Ctrl + 1~6

맨 위로 ↑

2 탭 · 여러 줄 탭

  • + 로 새 탭, × 로 닫기. 탭을 끌어 순서를 바꾸거나 다른 칸·창 밖으로 떼어 냅니다.
  • 탭이 넘치면 아래 줄로 내려갑니다 (설정 ▸ 일반에서 끌 수 있음).

단축키: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

맨 위로 ↑

3 즐겨찾기 줄

  • 자주 쓰는 폴더를 즐겨찾기 줄에 끌어다 놓으면 추가됩니다. 누르면 지금 칸에서 열립니다.
  • 우클릭으로 이름 바꾸기·지우기·묶음 만들기.

단축키: Ctrl + D

맨 위로 ↑

4 탐색 창 · 폴더 고정

  • 왼쪽 탐색 창 맨 위에 4Dir 즐겨찾기, 그 아래 Windows 즐겨찾기·내 PC.
  • 📌 폴더 고정을 켜면 다른 폴더를 열어도 트리가 그대로 — 펼쳐 둔 폴더로 파일을 끌어 옮길 때 편합니다.

맨 위로 ↑

5 주소줄

  • 경로 단추를 누르면 그 폴더로, 빈 곳을 누르면 경로를 직접 입력합니다.

단축키: Alt + D  ·  Ctrl + L

맨 위로 ↑

6 형식 단추

  • 맨 위 [전체][JPG][PNG]… 단추를 누르면 모든 칸이 그 형식만 보여 줍니다. Ctrl+누르기 = 여러 형식.

맨 위로 ↑

7 보기 방식

  • 자세히·목록·아이콘(작은~아주 큰)을 바꿉니다. 폴더마다·칸마다·전부 같게는 설정 ▸ 일반에서.

단축키: Ctrl + 휠

맨 위로 ↑

8 미리보기 창

  • 그림·동영상·PDF·문서를 고르면 바로 보입니다. PDF 는 쪽 넘기기, ✎ 편집으로 바로 편집.

단축키: Alt + P  ·  Space

맨 위로 ↑

9 메모

  • 할 일·체크 목록·그림을 붙여 두는 메모 창. 알림 시간도 넣을 수 있습니다.

단축키: Alt + M

맨 위로 ↑

파일 작업

10 칸끼리 복사 · 이동

  • 파일을 다른 칸으로 끌어 놓으면 복사(다른 드라이브) 또는 이동(같은 드라이브).
  • Ctrl 끌기 = 복사, Shift 끌기 = 이동. F6 / Shift+F6 = 고른 것을 옆 칸으로 복사 / 이동.

단축키: F6  ·  Shift + F6

맨 위로 ↑

11 탐색 창에 끌어 놓기

  • 파일을 왼쪽 탐색 창의 폴더 위에 놓아도 복사·이동됩니다.

맨 위로 ↑

12 옆 칸에 같은 폴더

  • 지금 폴더를 옆 칸에도 엽니다. 새 탭으로 열지, 보던 탭을 바꿀지는 설정 ▸ 일반에서.

단축키: Ctrl + =

맨 위로 ↑

13 글자로 찾기

  • 파일 목록에서 이름 앞글자를 빠르게 치면(1초 안) 그 이름으로 갑니다. 예: de → debug.

맨 위로 ↑

14 이름 바꾸기 · 일괄 변경

  • F2 = 이름 바꾸기 (확장명은 그대로). 여러 개를 고르고 F2 = 이름 일괄 변경 창(번호·바꾸기·대소문자).

단축키: F2

맨 위로 ↑

15 열 너비 자동 맞춤

  • 자세히 보기에서 긴 이름도 다 보이게 열 너비를 맞춥니다. 머리글 우클릭으로도.

단축키: Ctrl + Num +

맨 위로 ↑

도구

16 전체 검색

  • 맨 위 검색칸에 치면 색인한 폴더 전체에서 바로 찾습니다. 검색 범위는 설정 ▸ 검색.

단축키: Ctrl + Shift + F

맨 위로 ↑

17 두 칸 비교

  • 두 칸의 같은 이름 파일을 비교해 한쪽에만 있거나 더 새것을 골라 줍니다 → F6 으로 반대쪽에 복사.

단축키: Shift + F2

맨 위로 ↑

18 PDF 편집

  • PDF 우클릭 ▸ 4Dir 도구 ▸ PDF 편집 또는 미리보기의 ✎ 편집.
  • 쪽: 돌리기·지우기·순서·끼워 넣기 / 주석: 펜·형광펜·글상자 / 나누기: 쪽마다·범위·몇 쪽씩.

맨 위로 ↑

19 그림 편집

  • 그림 우클릭 ▸ 4Dir 도구 ▸ 그림 편집 또는 미리보기의 ✎ 편집 — 자르기·글자·화살표·모자이크·밝기.

맨 위로 ↑

20 내 PC

  • 드라이브마다 전체 크기·남은 공간과 사용량 막대 (윈도우 탐색기처럼).

맨 위로 ↑

21 설정

  • 언어·테마·창·탭·보기 방식·탐색 창·단축키·색상·검색·백업을 한곳에서. 바꾸면 바로 적용.

단축키: Ctrl + ,

맨 위로 ↑
