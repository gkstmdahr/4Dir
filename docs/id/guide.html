Area layar

1 Bagi panel (Tata letak)

  • Pakai tombol Tata letak di bilah alat untuk membagi menjadi 1·2·3·4·6 panel, atau kisi kustom (kolom×baris).
  • Setiap panel membuka folder dan tab-nya sendiri. Panel yang Anda klik diberi batas biru dan menjadi 'panel saat ini'.

Pintasan: Ctrl + 1~6

Kembali ke atas ↑

2 Tab · Tab multibaris

  • + untuk tab baru, × untuk menutup. Seret tab untuk mengubah urutan, atau pindahkan ke panel lain atau keluar dari jendela.
  • Tab tambahan dibungkus ke baris baru (bisa dinonaktifkan di Pengaturan ▸ Umum).

Pintasan: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

Kembali ke atas ↑

3 Bilah favorit

  • Seret folder yang sering dipakai ke bilah Favorit untuk menambahkannya. Klik untuk membukanya di panel saat ini.
  • Klik kanan untuk mengganti nama, menghapus, atau membuat grup.

Pintasan: Ctrl + D

Kembali ke atas ↑

4 Beranda

  • Seperti Beranda di Windows Explorer: folder favorit dan item terbaru terlihat sekaligus. Ada di bagian atas panel navigasi atau di bilah alamat: 'Beranda'.
  • Selama 4Dir berjalan, jendela baru yang dibuka dengan Win+E juga terbuka di Beranda.

Kembali ke atas ↑

5 Panel navigasi · Sematkan folder

  • Di bagian atas panel navigasi kiri: favorit 4Dir, lalu favorit Windows dan PC ini.
  • Aktifkan 📌 Sematkan folder dan pohon tetap di tempat saat Anda membuka folder lain — berguna untuk menyeret file ke folder yang diperluas.

Kembali ke atas ↑

6 Bilah alamat

  • Klik tombol jalur untuk ke folder itu; klik tempat kosong untuk mengetik jalur.

Pintasan: Alt + D  ·  Ctrl + L

Kembali ke atas ↑

7 Tombol jenis

  • Klik tombol [Semua][JPG][PNG]… di atas untuk menampilkan hanya jenis itu di semua panel. Ctrl+klik = beberapa jenis.

Kembali ke atas ↑

8 Tampilan

  • Beralih antara Detail, Daftar, dan Ikon (kecil hingga ekstra besar). Per folder, per panel, atau sama di mana-mana: Pengaturan ▸ Umum.

Pintasan: Ctrl + Roda

Kembali ke atas ↑

9 Panel pratinjau

  • Pilih gambar, video, PDF, atau dokumen, dan langsung tampil di panel kanan jendela 4Dir. Tombol ◀ ▶ atau < > menelusuri file di folder satu per satu.
  • Klik kanan pratinjau untuk melepasnya ke jendela terpisah, atau pilih 'Hanya isi' untuk memperbesar gambar/teks saja. Video: kecepatan 0.25–4×.
  • PDF bisa dibalik halamannya, dan ✎ Edit langsung mengeditnya.

Pintasan: Alt + P  ·  Space

Kembali ke atas ↑

10 Jadikan satu panel sebagai pratinjau

  • Menu Tampilan panel ▸ Jadikan panel ini pratinjau — panel ini menampilkan besar file yang dipilih di panel lain.
  • Klik ✕ Kembali ke daftar file di bagian atas panel untuk kembali ke daftar file.

Kembali ke atas ↑

11 Pratinjau folder

  • Jika Anda memilih folder di pratinjau, gambar dan video di dalamnya ditampilkan sebagai thumbnail. Aktifkan 'Sertakan subfolder' untuk menampilkan isi subfolder juga, per folder.
  • Klik thumbnail untuk melihatnya besar, lalu tekan Esc untuk kembali ke daftar.

Kembali ke atas ↑

12 Memilih kolom (kolom properti)

  • Klik kanan header kolom pada tampilan detail untuk mengaktifkan kolom properti Windows seperti status, atribut, deskripsi (memo), judul, dan tag.
  • Dengan 'Pilih kolom lain', Anda bisa mencari dan memilih semua properti seperti di Explorer.

Kembali ke atas ↑

13 Menu Saya

  • Pasang program, folder, alamat, dan fitur 4Dir yang sering dipakai di baris tombol atas. Alat ▸ Edit Menu Saya.
  • Atur pintasan dan ikon untuk setiap item (bisa hanya ikon), lalu kelompokkan dengan pemisah. Nilai yang diteruskan {files} = file yang dipilih.

Kembali ke atas ↑

14 Memo

  • Jendela catatan untuk daftar tugas, daftar periksa, dan gambar yang disematkan. Anda juga bisa mengatur waktu pengingat.

Pintasan: Alt + M

Kembali ke atas ↑

Operasi file

15 Salin · Pindah antarpanel

  • Seret file ke panel lain untuk menyalin (drive berbeda) atau memindahkan (drive sama).
  • Ctrl+seret = salin, Shift+seret = pindah. F6 / Shift+F6 = salin / pindahkan pilihan ke panel berikutnya.

Pintasan: F6  ·  Shift + F6

Kembali ke atas ↑

16 Jatuhkan ke panel navigasi

  • Menjatuhkan file ke folder di panel navigasi kiri juga menyalin atau memindahkannya.

Kembali ke atas ↑

17 Folder yang sama di panel berikutnya

  • Membuka folder saat ini di panel berikutnya juga. Tab baru atau ganti tab saat ini: Pengaturan ▸ Umum.

Pintasan: Ctrl + =

Kembali ke atas ↑

18 Ketik untuk mencari

  • Di daftar file, ketik cepat huruf pertama nama (dalam 1 detik) untuk melompat ke sana. Mis. de → debug.

Kembali ke atas ↑

19 Ganti nama · Ganti nama massal

  • F2 = ganti nama (ekstensi dipertahankan). Pilih beberapa lalu tekan F2 = jendela Ganti nama massal (penomoran, penggantian, huruf).

Pintasan: F2

Kembali ke atas ↑

20 Lebar kolom otomatis

  • Di tampilan Detail, menyesuaikan lebar kolom agar nama panjang tampil penuh. Juga lewat klik kanan pada header.

Pintasan: Ctrl + Num +

Kembali ke atas ↑

Alat

21 Cari semua

  • Ketik di kotak pencarian di atas untuk langsung mencari di semua folder yang diindeks. Cakupan pencarian: Pengaturan ▸ Cari.
  • Pencarian tidak hanya berdasarkan nama, tetapi juga kata di dalam dokumen (Excel, Word, PDF, Hangul (HWP)…) — memakai indeks Windows.

Pintasan: Ctrl + Shift + F

Kembali ke atas ↑

22 Bandingkan dua panel

  • Membandingkan file bernama sama di dua panel dan memilih yang hanya ada di satu sisi atau lebih baru → F6 menyalinnya ke sisi lain.

Pintasan: Shift + F2

Kembali ke atas ↑

23 Edit PDF

  • Klik kanan PDF ▸ Alat 4Dir ▸ Edit PDF, atau ✎ Edit di pratinjau.
  • Halaman: putar, hapus, ubah urutan, sisipkan / Anotasi: pena, stabilo, kotak teks / Pecah: per halaman, menurut rentang, setiap N halaman.

Kembali ke atas ↑

24 Editor gambar

  • Klik kanan gambar ▸ Alat 4Dir ▸ Edit gambar, atau ✎ Edit di pratinjau — pangkas, teks, panah, mosaik, kecerahan.

Kembali ke atas ↑

25 Aturan warna file

  • Alat ▸ Aturan warna file — mewarnai teks file berdasarkan ekstensi, nama, atau tanggal. Contoh: *.max biru, file yang berubah dalam 7 hari hijau.

Kembali ke atas ↑

26 Mode ringan

  • Pengaturan ▸ Umum ▸ Mode ringan — mematikan indeks pencarian cepat dan tampilan CPU serta mengurangi penyimpanan pratinjau agar memori lebih hemat.
  • Pencarian menyeluruh memindai folder saat itu juga sehingga sedikit lebih lambat. Jika dimatikan lagi, indeks tersimpan langsung dimuat.

Kembali ke atas ↑

27 PC ini

  • Ukuran total, ruang kosong, dan bilah penggunaan untuk tiap drive (seperti File Explorer).

Kembali ke atas ↑

28 Pengaturan

  • Bahasa, tema, jendela, tab, tampilan, panel navigasi, pintasan, warna, pencarian, dan cadangan di satu tempat. Perubahan langsung berlaku.

Pintasan: Ctrl + ,

Kembali ke atas ↑

Lainnya

  • Tema (terang/gelap) dan bahasa ada di ⚙ Pengaturan ▸ Umum. Perubahan bahasa berlaku setelah 4Dir dimulai ulang.
  • Jika 4Dir mulai bertingkah aneh, klik Alat → Simpan log untuk laporan masalah lalu kirim zip yang dibuat ke support@4dir.net. Kami akan memeriksa log untuk mencari penyebabnya.
