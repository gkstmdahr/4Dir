พื้นที่หน้าจอ

1 แบ่งบานหน้าต่าง (เค้าโครง)

  • ใช้ปุ่มเค้าโครงบนแถบเครื่องมือเพื่อแบ่งเป็น 1·2·3·4·6 บานหน้าต่าง หรือกริดกำหนดเอง (คอลัมน์×แถว)
  • แต่ละบานหน้าต่างเปิดโฟลเดอร์และแท็บของตัวเอง บานหน้าต่างที่คุณคลิกจะมีขอบสีน้ำเงินและกลายเป็น 'บานหน้าต่างปัจจุบัน'

แป้นลัด: Ctrl + 1~6

กลับขึ้นด้านบน ↑

2 แท็บ · แท็บหลายแถว

  • + สำหรับแท็บใหม่ × เพื่อปิด ลากแท็บเพื่อจัดลำดับ หรือย้ายไปบานหน้าต่างอื่นหรือออกนอกหน้าต่าง
  • แท็บส่วนเกินจะขึ้นแถวใหม่ (ปิดได้ใน การตั้งค่า ▸ ทั่วไป)

แป้นลัด: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

กลับขึ้นด้านบน ↑

3 แถบรายการโปรด

  • ลากโฟลเดอร์ที่ใช้บ่อยไปที่แถบรายการโปรดเพื่อเพิ่ม คลิกเพื่อเปิดในบานหน้าต่างปัจจุบัน
  • คลิกขวาเพื่อเปลี่ยนชื่อ ลบ หรือสร้างกลุ่ม

แป้นลัด: Ctrl + D

กลับขึ้นด้านบน ↑

4 หน้าแรก

  • เหมือนหน้าแรกของ File Explorer ใน Windows: เห็นโฟลเดอร์รายการโปรดและรายการล่าสุดในที่เดียว อยู่บนสุดของบานหน้าต่างนำทางหรือในแถบที่อยู่: 'หน้าแรก'
  • ขณะที่ 4Dir เปิดอยู่ หน้าต่างใหม่ที่เปิดด้วย Win+E ก็จะเปิดที่หน้าแรกเช่นกัน

กลับขึ้นด้านบน ↑

5 บานหน้าต่างนำทาง · ปักหมุดโฟลเดอร์

  • ที่ด้านบนของบานหน้าต่างนำทางทางซ้าย: รายการโปรด 4Dir ตามด้วยรายการโปรดของ Windows และ พีซีเครื่องนี้
  • เปิด 📌 ปักหมุดโฟลเดอร์ แผนผังจะอยู่กับที่เมื่อเปิดโฟลเดอร์อื่น — สะดวกเมื่อลากไฟล์ไปยังโฟลเดอร์ที่ขยายไว้

กลับขึ้นด้านบน ↑

6 แถบที่อยู่

  • คลิกปุ่มพาธเพื่อไปยังโฟลเดอร์นั้น คลิกที่ว่างเพื่อพิมพ์พาธ

แป้นลัด: Alt + D  ·  Ctrl + L

กลับขึ้นด้านบน ↑

7 ปุ่มชนิด

  • คลิกปุ่ม [ทั้งหมด][JPG][PNG]… ที่ด้านบนเพื่อแสดงเฉพาะชนิดนั้นในทุกบานหน้าต่าง Ctrl+คลิก = หลายชนิด

กลับขึ้นด้านบน ↑

8 มุมมอง

  • สลับระหว่างรายละเอียด รายการ และไอคอน (เล็กถึงใหญ่พิเศษ) ตามโฟลเดอร์ ตามบานหน้าต่าง หรือเหมือนกันทุกที่: การตั้งค่า ▸ ทั่วไป

แป้นลัด: Ctrl + ลูกกลิ้ง

กลับขึ้นด้านบน ↑

9 บานหน้าต่างแสดงตัวอย่าง

  • เลือกรูปภาพ วิดีโอ PDF หรือเอกสาร แล้วจะแสดงทันทีที่บานหน้าต่างด้านขวาของหน้าต่าง 4Dir ปุ่ม ◀ ▶ หรือ < > ใช้เลื่อนดูไฟล์ในโฟลเดอร์ทีละไฟล์
  • คลิกขวาที่ตัวอย่างเพื่อแยกเป็นหน้าต่างต่างหาก หรือเลือก 'เฉพาะเนื้อหา' เพื่อขยายเฉพาะรูปหรือข้อความ วิดีโอ: ความเร็ว 0.25–4×
  • PDF เปิดทีละหน้าได้ และ ✎ แก้ไข จะแก้ไขโดยตรง

แป้นลัด: Alt + P  ·  Space

กลับขึ้นด้านบน ↑

10 ใช้บานหน้าต่างหนึ่งเป็นตัวอย่าง

  • เมนูมุมมองของบานหน้าต่าง ▸ ใช้บานหน้าต่างนี้เป็นตัวอย่าง — บานหน้าต่างนี้จะแสดงไฟล์ที่เลือกในบานหน้าต่างอื่นแบบขนาดใหญ่
  • กด ✕ กลับไปที่รายการไฟล์ บนแถบหัวของบานหน้าต่างเพื่อกลับไปที่รายการไฟล์

กลับขึ้นด้านบน ↑

11 ตัวอย่างโฟลเดอร์

  • เมื่อเลือกโฟลเดอร์ในตัวอย่าง รูปภาพและวิดีโอข้างในจะแสดงเป็นภาพขนาดย่อ เปิด 'รวมโฟลเดอร์ย่อย' เพื่อแสดงของในโฟลเดอร์ย่อยด้วย แยกตามโฟลเดอร์
  • กดที่ภาพขนาดย่อเพื่อดูแบบใหญ่ และกด Esc เพื่อกลับไปที่รายการ

กลับขึ้นด้านบน ↑

12 เลือกคอลัมน์ (คอลัมน์คุณสมบัติ)

  • คลิกขวาที่หัวคอลัมน์ในมุมมองรายละเอียดเพื่อเปิดคอลัมน์คุณสมบัติของ Windows เช่น สถานะ แอตทริบิวต์ คำอธิบาย (บันทึกช่วยจำ) ชื่อเรื่อง และแท็ก
  • ที่ 'เลือกคอลัมน์เพิ่มเติม' คุณค้นหาและเลือกคุณสมบัติทั้งหมดได้เหมือน File Explorer

กลับขึ้นด้านบน ↑

13 เมนูของฉัน

  • ปักโปรแกรม โฟลเดอร์ ที่อยู่ และฟังก์ชันของ 4Dir ที่ใช้บ่อยไว้บนแถวปุ่มด้านบน เครื่องมือ ▸ แก้ไขเมนูของฉัน
  • ตั้งแป้นลัดและไอคอนให้แต่ละรายการ (แสดงเฉพาะไอคอนได้) และจัดกลุ่มด้วยเส้นคั่น ค่าที่ส่งต่อ {files} = ไฟล์ที่เลือก

กลับขึ้นด้านบน ↑

14 บันทึกช่วยจำ

  • หน้าต่างบันทึกสำหรับรายการสิ่งที่ต้องทำ รายการตรวจสอบ และรูปภาพที่ปักหมุด ตั้งเวลาเตือนได้ด้วย

แป้นลัด: Alt + M

กลับขึ้นด้านบน ↑

การทำงานกับไฟล์

15 คัดลอก · ย้ายระหว่างบานหน้าต่าง

  • ลากไฟล์ไปยังบานหน้าต่างอื่นเพื่อคัดลอก (ไดรฟ์ต่างกัน) หรือย้าย (ไดรฟ์เดียวกัน)
  • Ctrl+ลาก = คัดลอก, Shift+ลาก = ย้าย F6 / Shift+F6 = คัดลอก / ย้ายสิ่งที่เลือกไปยังบานหน้าต่างถัดไป

แป้นลัด: F6  ·  Shift + F6

กลับขึ้นด้านบน ↑

16 วางลงบนบานหน้าต่างนำทาง

  • การวางไฟล์ลงบนโฟลเดอร์ในบานหน้าต่างนำทางทางซ้ายก็คัดลอกหรือย้ายได้เช่นกัน

กลับขึ้นด้านบน ↑

17 โฟลเดอร์เดียวกันในบานหน้าต่างถัดไป

  • เปิดโฟลเดอร์ปัจจุบันในบานหน้าต่างถัดไปด้วย แท็บใหม่หรือแทนที่แท็บปัจจุบัน: การตั้งค่า ▸ ทั่วไป

แป้นลัด: Ctrl + =

กลับขึ้นด้านบน ↑

18 พิมพ์เพื่อค้นหา

  • ในรายการไฟล์ พิมพ์ตัวอักษรแรกๆ ของชื่ออย่างรวดเร็ว (ภายใน 1 วินาที) เพื่อข้ามไปที่นั่น เช่น de → debug

กลับขึ้นด้านบน ↑

19 เปลี่ยนชื่อ · เปลี่ยนชื่อเป็นกลุ่ม

  • F2 = เปลี่ยนชื่อ (คงนามสกุล) เลือกหลายรายการแล้วกด F2 = หน้าต่างเปลี่ยนชื่อเป็นกลุ่ม (ใส่หมายเลข แทนที่ ตัวพิมพ์)

แป้นลัด: F2

กลับขึ้นด้านบน ↑

20 ปรับความกว้างคอลัมน์อัตโนมัติ

  • ในมุมมองรายละเอียด ปรับความกว้างคอลัมน์เพื่อให้แสดงชื่อยาวทั้งหมด ใช้ผ่านการคลิกขวาที่ส่วนหัวได้ด้วย

แป้นลัด: Ctrl + Num +

กลับขึ้นด้านบน ↑

เครื่องมือ

21 ค้นหาทั้งหมด

  • พิมพ์ในช่องค้นหาด้านบนเพื่อค้นหาทุกโฟลเดอร์ที่จัดทำดัชนีทันที ขอบเขตการค้นหา: การตั้งค่า ▸ ค้นหา
  • ค้นหาได้ไม่เพียงจากชื่อ แต่ยังรวมถึงคำในเอกสาร (Excel, Word, PDF, Hangul (HWP)…) — ใช้ดัชนีของ Windows

แป้นลัด: Ctrl + Shift + F

กลับขึ้นด้านบน ↑

22 เปรียบเทียบสองบานหน้าต่าง

  • เปรียบเทียบไฟล์ชื่อเดียวกันในสองบานหน้าต่างและเลือกไฟล์ที่มีเฉพาะด้านเดียวหรือใหม่กว่า → F6 คัดลอกไปอีกฝั่ง

แป้นลัด: Shift + F2

กลับขึ้นด้านบน ↑

23 แก้ไข PDF

  • คลิกขวา PDF ▸ เครื่องมือ 4Dir ▸ แก้ไข PDF หรือ ✎ แก้ไข ในตัวอย่าง
  • หน้า: หมุน ลบ จัดลำดับ แทรก / ใส่คำอธิบายประกอบ: ปากกา ปากกาเน้นข้อความ กล่องข้อความ / แยก: ตามหน้า ตามช่วง ทุก N หน้า

กลับขึ้นด้านบน ↑

24 โปรแกรมแก้ไขรูปภาพ

  • คลิกขวารูปภาพ ▸ เครื่องมือ 4Dir ▸ แก้ไขรูปภาพ หรือ ✎ แก้ไข ในตัวอย่าง — ครอบตัด ข้อความ ลูกศร โมเสก ความสว่าง

กลับขึ้นด้านบน ↑

25 กฎสีไฟล์

  • เครื่องมือ ▸ กฎสีไฟล์ — ระบายสีตัวอักษรของไฟล์ตามนามสกุล ชื่อ หรือวันที่ ตัวอย่าง: *.max สีน้ำเงิน ไฟล์ที่เปลี่ยนภายใน 7 วันสีเขียว

กลับขึ้นด้านบน ↑

26 โหมดเบา

  • การตั้งค่า ▸ ทั่วไป ▸ โหมดเบา — ปิดดัชนีค้นหาเร็วและการแสดง CPU และลดการเก็บตัวอย่างไว้ เพื่อใช้หน่วยความจำน้อยลง
  • การค้นหาทั้งหมดจะไล่ดูโฟลเดอร์ ณ ตอนนั้น จึงช้าลงเล็กน้อย เมื่อปิดอีกครั้งจะโหลดดัชนีที่บันทึกไว้ทันที

กลับขึ้นด้านบน ↑

27 พีซีเครื่องนี้

  • ขนาดรวม พื้นที่ว่าง และแถบการใช้งานของแต่ละไดรฟ์ (เหมือน File Explorer)

กลับขึ้นด้านบน ↑

28 การตั้งค่า

  • ภาษา ธีม หน้าต่าง แท็บ มุมมอง บานหน้าต่างนำทาง แป้นพิมพ์ลัด สี ค้นหา และสำรองข้อมูลในที่เดียว การเปลี่ยนแปลงมีผลทันที

แป้นลัด: Ctrl + ,
