⚠ โปรแกรมป้องกันไวรัสบางตัว (Microsoft Defender, HP Wolf Security ฯลฯ) ระบุว่า 4Dir.exe ในไฟล์ zip เป็นมัลแวร์โดยผิดพลาด นี่เป็นผลบวกลวง
4Dir.exe เป็นตัวเปิดโปรแกรมขนาด 18 KB ที่ทำหน้าที่เปิดแอปเท่านั้น (ซอร์สโค้ด) และได้แจ้งไปยังผู้พัฒนาโปรแกรมป้องกันไวรัสแล้ว
Bitdefender ยืนยันแล้วว่าไฟล์ปลอดภัย และจะนำการตรวจพบนี้ออกในการอัปเดตที่จะมาถึง

คุณสมบัติ

สูงสุด 20 บานหน้าต่าง

จัดเลย์เอาต์ 1, 2, 3, 4 หรือ 6 บานหน้าต่างได้ในคลิกเดียว หรือจะตั้งตารางเองได้ถึง 5 × 4 ทุกบานหน้าต่างมีแท็บของตัวเอง

ไม่เกะกะการทำงาน

อ่านโฟลเดอร์โดยตรง ไม่ผ่านมุมมอง shell ของ Windows ที่หนักเครื่อง ไม่มีตัวจับเวลาหรือการโพลล์ขณะไม่ได้ใช้งาน — เปิดค้างไว้ข้าง 3ds Max เกม หรือแอปหนัก ๆ อื่น ๆ ได้อย่างสบายใจ

ค้นหาทันที

พิมพ์เพื่อค้นหาชื่อไฟล์ทั้งหมดในไดรฟ์ของคุณ ดัชนีของตัวเองอัปเดตแบบเรียลไทม์ — ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

ดูสถานะ SVN ได้ในพริบตา

ป้ายสถานะแก้ไข / เพิ่ม / ขัดแย้งอ่านตรงจาก .svn — โฟลเดอร์จะเปลี่ยนเป็นสีแดงเมื่อมีบางอย่างข้างในเปลี่ยนแปลง รองรับ Git และ Perforce ผ่านโอเวอร์เลย์ของ Windows

ใช้งานรู้สึกเหมือน Explorer

ปุ่มลัดเดียวกัน เมนูคลิกขวาของ Windows ครบถ้วน ลากและวางเข้า/ออกจาก Explorer และแอปอื่น ๆ ได้ คลิกขวาที่รูป .webp เพื่อบันทึกเป็น PNG หรือ JPG

พกพาได้และเป็นส่วนตัว

การตั้งค่าอยู่ในโฟลเดอร์ 4Dir ธีมสว่าง/มืด 26 ภาษา การเปลี่ยนชื่อเป็นชุด การกู้คืนเซสชัน และการตรวจสุขภาพ Explorer มีมาในตัว

วิธีติดตั้ง

  1. ดาวน์โหลดไฟล์ zip ด้วยปุ่มด้านบน (หรือจาก Releases บน GitHub) ปุ่มสีเขียว “Code → Download ZIP” บน GitHub เป็นเพียงซอร์สโค้ดและใช้งานไม่ได้
  2. คลิกขวาที่ไฟล์ zip → คุณสมบัติ → ติ๊ก เลิกบล็อก → ตกลง (ไม่เช่นนั้น Windows จะแสดงคำเตือนความปลอดภัยทุกครั้ง)
  3. แตกไฟล์ไว้ที่ไหนก็ได้ แล้วดับเบิลคลิก 4Dir.exe (หรือ 4Dir.vbs หาก 4Dir.exe ถูกบล็อก)

หาก Windows SmartScreen ปรากฏขึ้น: คลิก ข้อมูลเพิ่มเติม → เรียกใช้อยู่ดี

คำถามที่พบบ่อย

ฟรีจริงหรือ?

จริง 4Dir ฟรีและเป็นโอเพนซอร์ส (GPL-3.0) ไม่มีโฆษณา ไม่ต้องสมัครบัญชี ไม่มีช่วงทดลองใช้

ใช้ที่ทำงานได้ไหม?

ได้ 4Dir เป็นซอฟต์แวร์เสรีภายใต้ GPL-3.0 บริษัทจึงใช้ได้ฟรีเช่นกัน ไม่มีค่าลิขสิทธิ์หรือการลงทะเบียน เนื่องจากทำงานได้โดยไม่ต้องติดตั้ง เพียงตรวจสอบว่าบริษัทของคุณอนุญาตให้ใช้แอปแบบพกพา

เร็วกว่า File Explorer จริงหรือ?

การเปิดโฟลเดอร์ที่มี 1,000 ไฟล์ในหน้าต่างใหม่ใช้เวลา 0.4 วินาทีใน 4Dir และประมาณ 2 วินาทีใน File Explorer การเปิดอีกหนึ่งหน้าต่างใช้หน่วยความจำเพิ่มประมาณ 10 MB ใน 4Dir และประมาณ 130 MB ใน File Explorer วัดผลอย่างละ 5 ครั้งบนพีซีเครื่องเดียวกัน (Windows 11, SSD) หากโฟลเดอร์เดียวมีไฟล์หลายหมื่นไฟล์ ความต่างจะน้อยลง

ส่งข้อมูลอะไรออกไปไหม?

ไม่ส่งข้อมูลส่วนบุคคล ตรวจสอบเพียงวันละครั้งว่ามีเวอร์ชันใหม่หรือไม่ (ปิดได้ในเครื่องมือ)

เกิดปัญหาขึ้น?

เครื่องมือ → บันทึกล็อกสำหรับรายงานปัญหา แล้วกด “ส่งทางอีเมล” (หรืออีเมลไฟล์ zip ไปที่ support@4dir.net) ผู้ใช้ GitHub สามารถเปิด issue ได้เช่นกัน
