功能

最多 20 個窗格

一鍵切換 1、2、3、4、6 窗格配置，或自訂最多 5 × 4 的格狀配置。每個窗格都有獨立分頁。

不拖慢電腦

直接讀取資料夾，不使用笨重的 Windows Shell 檢視。閒置時沒有計時器與輪詢——可放心與 3ds Max、遊戲等大型程式同時開著。

即時搜尋

輸入即可搜尋所有磁碟上的檔名。自有索引即時更新，不需要系統管理員權限。

SVN 狀態一目了然

直接讀取 .svn 顯示修改/新增/衝突標記，內部有變更的資料夾顯示為紅色。Git、Perforce 透過 Windows 覆疊圖示顯示。

操作就像檔案總管

相同的快速鍵、完整的 Windows 右鍵選單，可與檔案總管及其他程式互相拖放。按右鍵即可把 .webp 圖片另存為 PNG 或 JPG。

免安裝且重視隱私

設定只存在 4Dir 資料夾內。內建淺色/深色主題、10 種語言、批次重新命名、工作階段還原與檔案總管診斷。

安裝方式

  1. 用上方按鈕（或 GitHub 的 Releases）下載 zip。GitHub 上綠色的「Code → Download ZIP」只有原始碼，無法直接執行。
  2. 在 zip 上按右鍵 → 內容 → 勾選解除封鎖 → 確定。（否則每次執行都會出現安全性警告）
  3. 解壓縮到任意位置，雙擊 4Dir.exe。（被攔截時用 4Dir.vbs）

如果出現 Windows SmartScreen：按其他資訊 → 仍要執行。

常見問題

真的免費嗎？

是的。4Dir 是免費開源軟體（GPL-3.0）。沒有廣告、不需帳號、沒有試用期。

可以在公司使用嗎？

可以。4Dir 是 GPL-3.0 免費軟體，公司也能免費使用，不需授權費或註冊。它不需安裝即可執行，請確認公司是否允許使用免安裝軟體。

真的比檔案總管快嗎？

以新視窗開啟含 1,000 個檔案的資料夾：4Dir 0.4 秒，檔案總管約 2 秒。多開一個視窗增加的記憶體：4Dir 約 10 MB，檔案總管約 130 MB。同一台電腦（Windows 11、SSD）各量 5 次。單一資料夾有數萬個檔案時差距會變小。

會傳送資料嗎？

不會傳送個人資料。每天只檢查一次是否有新版本（可在「工具」中關閉）。

遇到問題？

工具 → 儲存問題回報記錄，然後按「以電子郵件傳送」（或把 zip 寄到 support@4dir.net）。GitHub 使用者也可以開 issue。
