畫面區域說明

1 分割窗格（版面配置）

  • 用工具列的版面配置按鈕分為 1·2·3·4·6 個窗格，或自訂（欄×列）。
  • 每個窗格各自開啟資料夾和索引標籤。按下的窗格顯示藍色框線，成為「目前窗格」。

快速鍵: Ctrl + 1~6

回到頂端 ↑

2 索引標籤 · 多列索引標籤

  • + 新增索引標籤，× 關閉。拖曳索引標籤可調整順序，或移到其他窗格、拖出視窗。
  • 索引標籤過多時換到下一列（可在 設定 ▸ 一般 中關閉）。

快速鍵: Ctrl + T  ·  Ctrl + W  ·  Ctrl + Shift + T

回到頂端 ↑

3 我的最愛列

  • 將常用資料夾拖到我的最愛列即可新增。按下即在目前窗格中開啟。
  • 按右鍵可重新命名、刪除、建立群組。

快速鍵: Ctrl + D

回到頂端 ↑

4 常用

  • 像 Windows 檔案總管的常用一樣，一眼查看我的最愛資料夾和最近項目。在瀏覽窗格頂端或網址列點「常用」。
  • 4Dir 執行時，用 Win+E 開啟的新視窗也會以常用開啟。

回到頂端 ↑

5 瀏覽窗格 · 釘選資料夾

  • 左側瀏覽窗格頂端是 4Dir 我的最愛，下方是 Windows 我的最愛和本機。
  • 開啟 📌 釘選資料夾後，開啟其他資料夾時樹狀結構保持不變 — 方便把檔案拖到已展開的資料夾。

回到頂端 ↑

6 網址列

  • 按下路徑按鈕即前往該資料夾，按下空白處可直接輸入路徑。

快速鍵: Alt + D  ·  Ctrl + L

回到頂端 ↑

7 類型按鈕

  • 按下頂端的 [全部][JPG][PNG]… 按鈕，所有窗格只顯示該類型。Ctrl+按下 = 多種類型。

回到頂端 ↑

8 檢視

  • 切換詳細資料、清單、圖示（小~超大）。依資料夾、依窗格或全部相同：設定 ▸ 一般。

快速鍵: Ctrl + 滾輪

回到頂端 ↑

9 預覽窗格

  • 選取圖片、影片、PDF、文件，即可在 4Dir 視窗右側窗格立即預覽。用 ◀ ▶ 或 < > 鍵依序翻看資料夾中的檔案。
  • 在預覽上按右鍵可分離成獨立視窗，或用「僅內容」放大檢視圖片和文字。影片可 0.25–4 倍速播放。
  • PDF 可翻頁，按 ✎ 編輯直接編輯。

快速鍵: Alt + P  ·  Space

回到頂端 ↑

10 將一個窗格用作預覽

  • 在窗格的「檢視」選單 ▸ 將此窗格用作預覽 — 此窗格會以大圖顯示其他窗格中選取的檔案。
  • 按窗格標題列的 ✕ 返回檔案清單，即可回到原本的檔案清單。

回到頂端 ↑

11 資料夾預覽

  • 在預覽中選取資料夾，會把其中的圖片和影片以縮圖彙整顯示。開啟「包含子資料夾」後，子資料夾中的內容也會依資料夾分組顯示。
  • 按縮圖可放大檢視，按 Esc 返回清單。

回到頂端 ↑

12 選擇欄（內容欄）

  • 在「詳細資料」檢視的欄標題上按右鍵，可開啟狀態、屬性、備註、標題、標籤等 Windows 內容欄。
  • 透過「選擇更多欄」，可像檔案總管一樣搜尋並選擇所有內容。

回到頂端 ↑

13 我的選單

  • 把常用的程式、資料夾、位址和 4Dir 功能加到上方按鈕列。工具 ▸ 編輯我的選單。
  • 可為每個項目設定快速鍵和圖示（僅顯示圖示），並用分隔線分組。傳遞的值 {files} = 選取的檔案。

回到頂端 ↑

14 便箋

  • 可貼待辦、檢查清單、圖片的便箋視窗。還可設定提醒時間。

快速鍵: Alt + M

回到頂端 ↑

檔案操作

15 窗格間複製 · 移動

  • 將檔案拖到其他窗格即複製（不同磁碟機）或移動（同一磁碟機）。
  • Ctrl+拖曳 = 複製，Shift+拖曳 = 移動。F6 / Shift+F6 = 將所選項目複製 / 移動到相鄰窗格。

快速鍵: F6  ·  Shift + F6

回到頂端 ↑

16 拖放到瀏覽窗格

  • 將檔案放到左側瀏覽窗格的資料夾上也可複製或移動。

回到頂端 ↑

17 在相鄰窗格開啟同一資料夾

  • 在相鄰窗格中也開啟目前資料夾。新增索引標籤或取代目前索引標籤：設定 ▸ 一般。

快速鍵: Ctrl + =

回到頂端 ↑

18 輸入尋找

  • 在檔案清單中快速輸入名稱開頭（1 秒內）即可跳到該項。例：de → debug。

回到頂端 ↑

19 重新命名 · 批次重新命名

  • F2 = 重新命名（保留副檔名）。選取多個後按 F2 = 批次重新命名視窗（編號、取代、大小寫）。

快速鍵: F2

回到頂端 ↑

20 自動調整欄寬

  • 在詳細資料檢視中調整欄寬以完整顯示長名稱。也可在標題按右鍵。

快速鍵: Ctrl + Num +

回到頂端 ↑

工具

21 全域搜尋

  • 在頂端搜尋方塊中輸入即可立即搜尋所有已編製索引的資料夾。搜尋範圍：設定 ▸ 搜尋。
  • 不只依名稱，也能依文件內的字詞（Excel、Word、PDF、韓文(HWP)…）搜尋 — 使用 Windows 索引。

快速鍵: Ctrl + Shift + F

回到頂端 ↑

22 比較兩個窗格

  • 比較兩個窗格中同名檔案，選出僅一側存在或較新的檔案 → 按 F6 複製到另一側。

快速鍵: Shift + F2

回到頂端 ↑

23 編輯 PDF

  • 在 PDF 按右鍵 ▸ 4Dir 工具 ▸ 編輯 PDF，或預覽中的 ✎ 編輯。
  • 頁面：旋轉、刪除、排序、插入 / 註解：筆、螢光筆、文字方塊 / 分割：每頁、依範圍、每 N 頁。

回到頂端 ↑

24 圖片編輯

  • 在圖片按右鍵 ▸ 4Dir 工具 ▸ 編輯圖片，或預覽中的 ✎ 編輯 — 裁切、文字、箭頭、馬賽克、亮度。

回到頂端 ↑

25 檔案色彩規則

  • 工具 ▸ 檔案色彩規則 — 依副檔名、名稱、日期條件為檔案文字上色。例：*.max 藍色，7 天內修改的檔案綠色。

回到頂端 ↑

26 輕量模式

  • 設定 ▸ 一般 ▸ 輕量模式 — 關閉快速搜尋索引和 CPU 顯示，並減少預覽快取，以節省記憶體。
  • 全部搜尋會即時掃描資料夾，速度會稍慢。再次關閉後，會立即載入已儲存的索引。

回到頂端 ↑

27 本機

  • 每個磁碟機的總大小、可用空間和使用量列（如同檔案總管）。

回到頂端 ↑

28 設定

  • 語言、佈景主題、視窗、索引標籤、檢視、瀏覽窗格、快速鍵、色彩、搜尋、備份集中設定。變更立即生效。

快速鍵: Ctrl + ,

回到頂端 ↑

其他

  • 淺色/深色和語言在檢視功能表裡。語言要重新啟動 4Dir 才會切換。
