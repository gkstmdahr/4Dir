版本記錄

4Dir 的所有版本及更新內容。建議使用最新版本；舊版本也保留在這裡以備需要。

v0.9.97 最新

2026-11-05⬇ 下載 SHA256
  • 圖示檢視：修正在資料夾與檔案混合的位置（例如磁碟根目錄）名稱被截斷的問題。
  • 拔出磁碟後，位於該磁碟上的分頁會轉到「本機」，不再顯示舊清單。
  • 回應慢的磁碟：開啟仍在啟動的磁碟（如剛插入的外接硬碟）時 4Dir 不再卡住，磁碟回應後即開啟，圖示和名稱也會隨後更新。
  • 安全移除：Windows 要退出 USB 或外接磁碟時，4Dir 會釋放它，不再提示「正在使用」。
  • 通知列：右側的 ✕ 按鈕可關閉。

v0.9.95

2026-11-05⬇ 下載 SHA256
  • 鎖定分頁：在分頁上按右鍵 > 鎖定分頁。在鎖定的分頁（🔒）中開啟資料夾時，會在旁邊的新分頁中開啟。
  • USB 與外接磁碟：插入後立即顯示在「本機」中，拔出後消失。

v0.9.94

2026-11-04⬇ 下載 SHA256
  • 狀態欄：在 OneDrive 等同步資料夾中顯示僅雲端、在此裝置上、一律保留（與檔案總管相同）。
  • 在檔案上按 Ctrl+Enter：在新索引標籤中開啟其所在資料夾（搜尋結果與捷徑），如 Everything 的開啟路徑。
  • 匯出/匯入設定（工具）：檢視、快速鍵、我的最愛、視窗與索引標籤（含色彩）、色彩標籤 — 重灌後一次還原。
  • 更快：大型資料夾開啟速度約提升一倍（3 萬個檔案：1.3 秒 → 0.5 秒）。

v0.9.93

2026-11-04⬇ 下載 SHA256
  • 依日期分組（今天、昨天、本週…），與 Windows 檔案總管相同 — 在 檢視 > 顯示 中開啟。
  • 版面配置：新增 8 種（如左側 1 個長窗格 + 右側 2 個、3 + 1）— 按一個版面配置按鈕即可選擇。
  • 資料夾大小：大小欄也顯示資料夾大小，可依大小排序（網路磁碟機除外）。
  • 比較兩個窗格（Shift+F2）：僅一側有或較新的檔案會標色並選取 — 按 F6 複製到另一側。
  • 依模式選取（Ctrl+Shift+A），例如 *.max; *_stand*。
  • 色彩：右鍵分頁 > 分頁色彩（13 種或任意色彩），右鍵檔案 > 色彩標籤（僅儲存在 4Dir 內）。
  • 尋找命令（Ctrl+Shift+P）：輸入任一功能或選單名稱的一部分後按 Enter。
  • 檢查碼：右鍵檔案 > 檢視檢查碼 (SHA256)。
  • 雙擊空白處回上層現在在清單左右兩側的空白條上也可用。
  • 關閉即結束：網路我的最愛回應緩慢時，關閉視窗後 4Dir 仍殘留一分鐘以上的問題已修正。

v0.9.71

2026-10-29⬇ 下載 SHA256
  • 新功能：即使在使用其他程式，按 Ctrl+Alt+F 即可叫出 4Dir 並直接在搜尋框輸入。可在 工具 → 快速鍵設定 中變更按鍵。

  • 更新提示更安全：前往下載 只會開啟本網站或本專案的 GitHub 頁面，其他位址一律忽略。
