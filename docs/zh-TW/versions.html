版本記錄

4Dir 的所有版本及更新內容。建議使用最新版本；舊版本也保留在這裡以備需要。

v0.9.132 最新

2026-11-11⬇ 下載 SHA256
  • 資料夾預覽：包含子資料夾：在預覽窗格中勾選包含子資料夾，即可依資料夾分組、以一條長捲動清單檢視所選資料夾及其子資料夾中的所有圖片和影片（最多 2,000 個）。用每列數量設定一列放幾個。

  • 上方的 CPU 使用率現在與工作管理員一致（相同計數器），每秒更新。
