版本記錄

4Dir 的所有版本及更新內容。建議使用最新版本；舊版本也保留在這裡以備需要。

v0.9.72 最新

2026-10-29⬇ 下載 SHA256
  • 修正：部分檔案上的版本控制疊加圖示（Git、Perforce 等）有時不顯示的問題。

v0.9.71

2026-10-29⬇ 下載 SHA256
  • 新功能：即使在使用其他程式，按 Ctrl+Alt+F 即可叫出 4Dir 並直接在搜尋框輸入。可在 工具 → 快速鍵設定 中變更按鍵。
  • 在網址列輸入 cmd 或 powershell 即可在目前資料夾中開啟——與 Windows 檔案總管相同。
  • 搜尋框取得焦點時會顯示藍色外框，視窗變窄時搜尋框也不會被隱藏。
  • 搜尋沒有結果時會說明原因（網路磁碟機和 Google 雲端硬碟一開始不在搜尋範圍內），並提供變更搜尋範圍的按鈕。
  • 更新提示更安全：前往下載 只會開啟本網站或本專案的 GitHub 頁面，其他位址一律忽略。

v0.9.67

2026-10-24⬇ 下載 SHA256
  • 修正：在圖示和清單檢視中拖曳檔案時，會選取多個檔案而不是移動。
  • 拖曳時圖片檔案會顯示其本身的畫面，並從你抓取的位置跟隨滑鼠——與 Windows 檔案總管相同。
