Funzionalità

Fino a 20 riquadri

Layout a 1, 2, 3, 4 o 6 riquadri con un clic, oppure qualsiasi griglia fino a 5 × 4. Ogni riquadro ha le sue schede.

Non dà fastidio

Le cartelle vengono lette direttamente, senza la pesante vista della shell di Windows. Nessun timer né polling a riposo: lo puoi tenere aperto accanto a 3ds Max, giochi o altre app pesanti.

Ricerca istantanea

Digita per cercare tra tutti i nomi di file dei tuoi dischi. L'indice si aggiorna in tempo reale, senza bisogno dei diritti di amministratore.

Stato SVN a colpo d'occhio

I badge di modificato / aggiunto / conflitto vengono letti direttamente da .svn: le cartelle diventano rosse quando qualcosa al loro interno cambia. Git e Perforce tramite le icone di sovrapposizione di Windows.

Come Esplora file

Stesse scorciatoie da tastiera, menu contestuale completo di Windows, trascinamento da e verso Esplora file e altre app. Fai clic con il pulsante destro su un'immagine .webp per salvarla come PNG o JPG.

Portatile e riservato

Le impostazioni restano nella cartella di 4Dir. Tema chiaro/scuro, 26 lingue, rinomina multipla, ripristino della sessione e controllo dello stato di Esplora file integrati.

Come installare

  1. Scarica lo zip con il pulsante qui sopra (oppure da GitHub Releases). Il pulsante verde “Code → Download ZIP” di GitHub contiene solo il codice sorgente e non si avvia.
  2. Fai clic con il pulsante destro sullo zip → Proprietà → seleziona Sblocca → OK. (Altrimenti Windows mostra un avviso di sicurezza ogni volta.)
  3. Estrailo dove vuoi e fai doppio clic su 4Dir.exe. (oppure 4Dir.vbs se 4Dir.exe è bloccato)

Se compare Windows SmartScreen: fai clic su Ulteriori informazioni → Esegui comunque.

Domande frequenti

È davvero gratuito?

Sì. 4Dir è gratuito e open source (GPL-3.0). Niente pubblicità, niente account, niente prova a tempo.

Posso usarlo al lavoro?

Sì. 4Dir è software libero GPL-3.0, quindi anche le aziende possono usarlo gratuitamente, senza costi di licenza né registrazione. Poiché funziona senza installazione, verifica solo che la tua azienda consenta le app portatili.

È davvero più veloce di Esplora file?

Aprire in una nuova finestra una cartella con 1.000 file ha richiesto 0,4 s in 4Dir e circa 2 s in Esplora file. Aprire una finestra in più ha aggiunto circa 10 MB di memoria in 4Dir e circa 130 MB in Esplora file. Misurato 5 volte ciascuno sullo stesso PC (Windows 11, SSD). Con decine di migliaia di file in una sola cartella la differenza si riduce.

Invia dati?

Nessun dato personale. Controlla solo una volta al giorno se esiste una nuova versione (puoi disattivarlo in Strumenti).

Qualcosa non va?

Strumenti → Salva il log per la segnalazione del problema, poi premi “Invia per e-mail” (oppure invia lo zip a support@4dir.net). Chi usa GitHub può anche aprire una issue.
