Funcții

Până la 20 de panouri

Aranjări cu 1, 2, 3, 4 sau 6 panouri dintr-un clic, sau orice grilă până la 5 × 4. Fiecare panou are filele lui.

Nu te încurcă

Folderele sunt citite direct, fără vizualizarea grea a shell-ului Windows. Fără temporizatoare sau interogări la repaus — îl poți ține deschis lângă 3ds Max, jocuri sau alte aplicații grele.

Căutare instantanee

Scrie ca să cauți orice nume de fișier de pe unitățile tale. Indexul propriu se actualizează în timp real — nu e nevoie de drepturi de administrator.

Starea SVN dintr-o privire

Insigne de modificat / adăugat / conflict citite direct din .svn — folderele devin roșii când se schimbă ceva în ele. Git și Perforce prin suprapunerile Windows.

Ca în Explorer

Aceleași comenzi rapide de la tastatură, meniul complet Windows de clic dreapta, glisare și plasare către și dinspre Explorer și alte aplicații. Clic dreapta pe o imagine .webp pentru a o salva ca PNG sau JPG.

Portabil și privat

Setările rămân în folderul 4Dir. Temă luminoasă/întunecată, 26 de limbi, redenumire în masă, restaurarea sesiunii și o verificare a stării Explorer, toate integrate.

Cum se instalează

  1. Descarcă arhiva zip cu butonul de mai sus (sau din Releases pe GitHub). Butonul verde „Code → Download ZIP” de pe GitHub conține doar codul sursă și nu va rula.
  2. Clic dreapta pe zip → Proprietăți → bifează Deblocare → OK. (Altfel Windows afișează un avertisment de securitate de fiecare dată.)
  3. Dezarhivează-l oriunde și dă dublu clic pe 4Dir.exe. (sau pe 4Dir.vbs dacă 4Dir.exe este blocat)

Dacă apare Windows SmartScreen: dă clic pe Mai multe informații → Executare oricum.

Întrebări frecvente

Este chiar gratuit?

Da. 4Dir este gratuit și open source (GPL-3.0). Fără reclame, fără cont, fără perioadă de probă.

Îl pot folosi la serviciu?

Da. 4Dir este software liber GPL-3.0, deci și firmele îl pot folosi gratuit, fără taxă de licență sau înregistrare. Fiind fără instalare, verifică doar dacă firma ta permite aplicațiile portabile.

Este chiar mai rapid decât File Explorer?

Deschiderea unui folder cu 1.000 de fișiere într-o fereastră nouă a durat 0,4 s în 4Dir și aproximativ 2 s în File Explorer. Încă o fereastră deschisă a adăugat circa 10 MB de memorie în 4Dir și circa 130 MB în File Explorer. Măsurat de câte 5 ori pe același PC (Windows 11, SSD). Cu zeci de mii de fișiere într-un singur folder diferența scade.
